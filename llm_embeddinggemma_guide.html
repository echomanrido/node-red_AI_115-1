核心幾何原理

深度解析：什麼是 Embedding（嵌入向量）？

電腦本質上不懂人類的語言符號，它只懂得做矩陣運算。Embedding（嵌入向量） 就是將人類的語言、文字或段落，投影到一個「高維度連續語意空間」的數學座標。

語意空間向量平移關係示意圖 (Semantic Vector Space) 經典幾何關係：國王 - 男人 + 女人 ≈ 女王
高維度特徵空間

圖片中執行的 embeddinggemma 會將輸入內容壓縮成高達數百至上千維的浮點數向量。每個維度代表模型在訓練過程中學習到的潛在語意特徵（如情感、領域、主題等）。

幾何方向代表語意

Embedding 的精髓在於方向性。只要兩個句子的意思相近（例如「今天好冷」與「氣溫偏低」），在多維空間中的夾角就極小，餘弦值趨近於 1。

L2 正則化（Unit Vector）

Ollama 的向量輸出通常經過 L2 正則化，使得向量長度（模長）固定為 1。這意味著在向量資料庫比對時，計算點積 (Dot Product) 就能直接等同於餘弦相似度，大幅提升檢索效能。

數學度量方法

為什麼使用餘弦相似度（Cosine Similarity）？

向量比對看的是「夾角方向」，而非文字長短。即使一個句子很長、另一個句子很短，只要語意相同，它們的方向向量夾角 $\theta$ 就極小，$\cos(\theta) \approx 1$。

餘弦相似度幾何夾角對比 (Cosine Angle Comparison) cos(θ) = (A · B) / (||A|| ||B||)
常見疑問解析

為什麼使用 Ollama 不需要手動指定或載入 Tokenizer？

在傳統 Python AI 開發中（例如使用 Hugging Face 的 transformers 套件），我們必須手動調用 AutoTokenizer.from_pretrained(...) 分詞後才能送給模型。那為什麼在 Ollama 只要執行一行指令就能直接輸出向量？

答案不是「沒有 Tokenizer」，而是「Ollama 已經幫你端到端封裝好了」！

Ollama 採用 GGUF 模型封裝規格。模型權重檔案內已經自帶完整的詞元表（Vocabulary）、BPE/SentencePiece 分詞邏輯與特殊標記配置。底層由 C++ (llama.cpp) 在接收到文字後，自動完成從字串到 Token ID、再到神經網絡推論的全自動管道。

處理流程架構對比 (Architecture Pipeline) 端到端 (End-to-End) 引擎自動化

GGUF 格式的一體化特性

過去模型權重檔（.bin / .safetensors）和分詞器（tokenizer.json）是分開存放的。而 Ollama 使用的 GGUF 格式將架構超參數、詞元對應表、正規化規則和模型權重整合成單一二進位檔案，因此推論引擎可自主執行分詞，無需使用者掛載外部 Tokenizer。

開發體驗極簡化

開發者不必再操心「最大長度截斷（Truncation）」、「補齊空白（Padding）」、「Pooling 策略是取 CLS Token 還是 Mean」等煩人的前置作業，直接輸入文字，Ollama 即可保證產出規格一致的標準向量。

Embedding 在 RAG 系統中的完整流通路徑

向量不是終點，而是現代大型語言模型（LLM）精準檢索企業知識庫的橋樑。以下是從文本切塊、向量化到精準問答的完整系統全景：

向量檢索增強生成全景 (RAG Vector Architecture) Offline Ingestion + Online Retrieval

語意高維空間

向量是一連串浮點數（例如 768 或 1024 個數字）。意思相似的文字（例如「狗」與「小狗」）在高維空間中的幾何距離會非常接近。

解決傳統關鍵字盲點

傳統搜尋只能依靠字面完全吻合；透過向量的「餘弦相似度 (Cosine Similarity)」，即使完全沒有相同的字詞也能找到同義文章。

RAG 向量資料庫引擎

搭配 ChromaDB、Qdrant、Milvus 或 pgvector 等向量資料庫，將企業文件切片並存入，能讓大語言模型精準檢索相關知識。

正式開發呼叫方式

終端機管道適合快速驗證；在應用程式中建議使用 Ollama 的專屬 REST API：/api/embed

呼叫本機 Ollama 服務產生向量 
curl -X POST http://localhost:11434/api/embed \
  -H "Content-Type: application/json" \
  -d '{
    "model": "embeddinggemma",
    "input": "The quick brown fox jumps over the lazy dog."
  }'
使用官方 Python 客戶端 (pip install ollama) 
import ollama

response = ollama.embed(
    model='embeddinggemma',
    input='The quick brown fox jumps over the lazy dog.'
)

# 取得向量陣列與長度
vector = response['embeddings'][0]
print(f"向量長度 (維度): {len(vector)}")
print(f"前 5 個數值: {vector[:5]}")
使用官方 NPM 套件 (npm install ollama) 
import ollama from 'ollama';

const response = await ollama.embed({
  model: 'embeddinggemma',
  input: 'The quick brown fox jumps over the lazy dog.',
});

console.log('維度大小:', response.embeddings[0].length);
console.log('第一筆向量:', response.embeddings[0]);
