OpenCart 後台原生 API (Native API) 串接架構全解

在智慧製造跨廠區部署或雲端電商環境中，直接暴露 MariaDB 3306 埠位往往存在資安風險。OpenCart 原生內建了以 IP 白名單與 API Key 為核心的 REST 認證機制。本方案透過 C# .NET 8 / HttpClient 實作 Session 與 Token 自動續期、工單查詢與完工歷史回寫，並提供傳統逐步指引與 Vibe Coding 提示詞工程！

OpenCart 原生 API (Native API) 運作原理

OpenCart 原生 API 核心路由位於 index.php?route=api/...。呼叫端必須先將請求來源 IP 加入後台白名單，透過 API Username 與 API Key 向 api/login 端點取得認證 Token / Session Cookie，後續所有查詢訂單、變更狀態均需附帶該 Session。

[C# .NET 8 MES 客戶端] [OpenCart 原生 API (PHP)] │ │ (1) ├────── POST index.php?route=api/login ───────────────────────►│ [比對 IP 白名單] │ Body: { username: "mes_agent", key: "sec_key_xxx" } │ [驗證 Key 有效性] │ │ (2) │◄───── 200 OK + api_token & Set-Cookie: OCSESSID=... ────────┤ [建立 API Session] │ │ (3) ├────── GET index.php?route=api/order/info&order_id=10 ───────►│ [檢查 Session 權限] │ Cookie: OCSESSID=... & api_token=... │ [提取訂單品項與選項] │ │ (4) │◄───── 200 OK + { order: { id: 10, total: 445, ... } } ───────┤ │ │ (5) ├────── POST index.php?route=api/order/history ───────────────►│ [更新狀態 Complete(5)] │ Body: { order_status_id: 5, comment: "CNC切削合格" } │ [自動寫入 oc_order_history] ▼ ▼

步驟四：實作 C# 原生 API 認證客戶端 (保持 Session 與 Token)

建立 OpenCartNativeApiClient.cs，使用 CookieContainer 自動維護登入後的 Session Cookie：

OpenCartNativeApiClient.cs (認證實作) 
using System;
using System.Net;
using System.Net.Http;
using System.Text.Json;
using System.Threading.Tasks;

public class OpenCartNativeApiClient
{
    private readonly HttpClient _httpClient;
    private readonly CookieContainer _cookies = new();
    private readonly string _baseUrl;
    private string? _apiToken;

    public OpenCartNativeApiClient(string baseUrl = "http://localhost/opencart-4.0.2.2/upload/")
    {
        _baseUrl = baseUrl.TrimEnd('/') + "/";
        var handler = new HttpClientHandler { CookieContainer = _cookies, UseCookies = true };
        _httpClient = new HttpClient(handler);
    }

    // 1. 執行原生 API 登入並取得 Token
    public async Task<bool> LoginAsync(string username, string apiKey)
    {
        var loginUrl = $"{_baseUrl}index.php?route=api/login";
        var formData = new MultipartFormDataContent
        {
            { new StringContent(username), "username" },
            { new StringContent(apiKey), "key" }
        };

        var response = await _httpClient.PostAsync(loginUrl, formData);
        var jsonStr = await response.Content.ReadAsStringAsync();
        using var doc = JsonDocument.Parse(jsonStr);

        if (doc.RootElement.TryGetProperty("api_token", out var tokenProp))
        {
            _apiToken = tokenProp.GetString();
            Console.WriteLine($"[API] 登入成功！取得 Token: {_apiToken}");
            return true;
        }

        if (doc.RootElement.TryGetProperty("error", out var errProp))
        {
            Console.WriteLine($"[API] 登入失敗：{errProp}");
        }
        return false;
    }
}

步驟五：實作工單查詢與訂單明細提取 (GET order/info)

登入成功後，帶著 api_token 向 api/order/info 端點提取買家姓名、下單時間與總金額：

提取工單明細函式 
    // 2. 依 order_id 提取工單詳細資料
    public async Task<string?> GetOrderInfoAsync(int orderId)
    {
        if (string.IsNullOrEmpty(_apiToken)) throw new InvalidOperationException("請先執行 LoginAsync 認證！");

        var url = $"{_baseUrl}index.php?route=api/order/info&api_token={_apiToken}&order_id={orderId}";
        var response = await _httpClient.GetAsync(url);
        var jsonResult = await response.Content.ReadAsStringAsync();
        
        Console.WriteLine($"[API] 工單 #{orderId} 查詢結果：
{jsonResult}");
        return jsonResult;
    }

步驟六：機台完工狀態變更與品質歷程自動回寫 (POST order/history)

當 CNC 虛擬機台切削完成後，呼叫 api/order/history 回傳狀態碼 5 (Complete)，OpenCart 會自動在後台完成訂單轉態與歷程寫入：

完工回寫函式 
    // 3. 完工回寫訂單狀態與品質追溯備註
    public async Task<bool> UpdateOrderStatusAsync(int orderId, int statusId, string comment)
    {
        if (string.IsNullOrEmpty(_apiToken)) throw new InvalidOperationException("未完成 API 登入！");

        var url = $"{_baseUrl}index.php?route=api/order/history&api_token={_apiToken}&order_id={orderId}";
        var form = new MultipartFormDataContent
        {
            { new StringContent(statusId.ToString()), "order_status_id" },
            { new StringContent(comment), "comment" },
            { new StringContent("1"), "notify" }
        };

        var response = await _httpClient.PostAsync(url, form);
        var resText = await response.Content.ReadAsStringAsync();
        Console.WriteLine($"[API] 完工回寫回應：{resText}");
        return response.IsSuccessStatusCode && resText.Contains("success");
    }

   - 使用 CookieContainer 與 SocketsHttpHandler 維護 Session Cookie (OCSESSID)。
   - 提供非同步方法 LoginAsync(string username, string apiKey)。
   - 發送 multipart/form-data 至 route=api/login，解析回傳之 api_token 並安全儲存。
   - 若 Session 過期或回傳授權錯誤，需具備自動重新認證 (Token Refresh) 機制。
2. 規範：
   - 使用 C# 最新語法、強型別、完善的例外處理與 ILogger 日誌紀錄。

Prompt 2：工單查詢與強型別 DTO 模型映射
