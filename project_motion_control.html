PC-Based 運動控制軸卡與工業 IO 卡整合實戰
大銀微系統 PCI4P 四軸軸卡・研華 PCI-1756 隔離 IO 卡・MCCL 運動函式庫・多軸插補運動

在精密半導體設備、龍門型加工機 (Gantry) 與四軸機械手臂 (X, Y, Z, Θ) 中，傳統 PLC 難以滿足高速脈衝 (2.44 Mpps) 與微秒級多軸軌跡插補的需求。本專題以大銀微系統 (HIWIN MIKROSYSTEM) 四軸運動卡 PCI4P 與 研華 (Advantech) PCI-1756 64通道光隔離數位 IO 卡 為核心，詳細剖析 MCCL (Motion Control Command Library) 運動命令函式庫從硬體初始化、機構參數設定、AB相編碼器回授、原點復歸 (Homing 16種模式)、多軸運動群組建置 (Group)，到直線/圓弧/螺旋軌跡插補、寸動 (Jog) 與背隙補償 (Backlash Compensation) 的完整 C# 實務開發心法！

硬體軸卡核心 2.44 Mpps 高速脈衝

大銀 PCI4P 四軸運動控制卡

支援 PCI 匯流排，單卡獨立控制 4 軸伺服/步進馬達，全系統最高可擴充 12 張卡 (72 軸同控)。內建硬體極限保護開關、高速編碼器計數器與驅動器致能迴路。

高壓光隔離防護 2,500 VDC 隔離

研華 PCI-1756 64通道 IO 卡

具備 32 通道隔離輸入 (DI) 與 32 通道隔離輸出 (DO，每通道可承受 200mA 大電流)。支援輸出狀態回讀 (Readback) 與系統熱重置保持狀態，杜絕突波雜訊干擾。

空間軌跡演算法 1~50 ms 插補週期

MCCL 運動命令庫 (7大步驟)

提供點對點 (PTP)、連續直線補間、圓弧、圓與螺旋軌跡規劃。內建 S-Curve 與 T-Curve 加減速平滑濾波，支援非同步命令佇列 (Command Queue) 與即時位置回授監控。

品質精度管理 6σ / Cpk ≥ 1.33

精度・重複性與背隙補償

釐清解析度 (Resolution)、精度 (Accuracy) 與重複精度 (Repeatability)。掌握全閉迴路光學尺回授、螺桿背隙 (Backlash) 補償計算，並結合工控 Six Sigma 製程能力指數！

MCCL (Motion Control Command Library) 啟動運動函式庫 7 大步驟實戰

1

Step 1：設定機構參數 (Mechanism Parameters)

機構方向與速度極限

設定馬達旋轉與機械實際移動方向之對應關係，並定義最高安全轉速與每轉脈波數。透過軟體參數調整，工程師無需更改馬達實體配線即可修正方向：

// 宣告機構參數結構體並初始化 SYS_MAC_PARAM stAxisParam = new SYS_MAC_PARAM(); stAxisParam.wPosToEncoderDir = 0; // 方向調整參數：0=輸出命令不反向, 1=輸出命令反向 (免改馬達接線) stAxisParam.dwRPM = 3000; // 馬達最大安全轉速限制 (轉/分)，防止機構超速損壞 stAxisParam.dwPPR = 10000; // 馬達每旋轉一圈所需的脈波數 (Pulse Per Revolution) stAxisParam.dfPitch = 5.0; // 滾珠螺桿導程 (單位: mm/轉) // 套用至指定 Channel (以 Channel 0 為例) int nRet = MCCL.MCC_SetMacParam(ref stAxisParam, 0, MCCL.CARDINDEX0);
2

Step 2：設定編碼器參數 (Encoder Configuration)

AB相四倍頻解析

配置光學編碼器回授格式。工業標準大多採用 A/B Phase 90° 相位差，透過硬體四倍頻 (4x Multiplier) 計算，可將解析度提升 4 倍：

SYS_ENCODER_CONFIG stENCConfig = new SYS_ENCODER_CONFIG(); stENCConfig.wType = MCCL.ENC_TYPE_AB; // 輸入格式：ENC_TYPE_AB (A/B相), ENC_TYPE_CW, ENC_TYPE_PD stENCConfig.wAInverse = MCCL.INVERSE_NO; // Phase A 訊號是否反相 (0=不反相, 1=反相) stENCConfig.wBInverse = MCCL.INVERSE_NO; // Phase B 訊號是否反相 stENCConfig.wCInverse = MCCL.INVERSE_NO; // Phase C (Index/Z相) 訊號是否反相 stENCConfig.wABSwap = MCCL.INVERSE_NO; // Phase A/B 訊號是否交換 (可變更正負計數方向) stENCConfig.wInputRate = 4; // 編碼器回授倍率：4 代表 4 倍頻 (×4 鑑別微步位移) // 寫入軸卡暫存器 nRet = MCCL.MCC_SetEncoderConfig(ref stENCConfig, 0, MCCL.CARDINDEX0);
3

Step 3：設定原點復歸參數 (Home Configuration - 16種模式)

機械與邏輯原點校正

MCCL 提供多達 16 種原點復歸模式。模式 3 (wMode = 3) 廣泛應用於工業台：以高速 dfHighSpeed 尋找原點開關 (Home Sensor)，觸發後減速停止，接著根據 dfOffset 位移至精密的邏輯原點：

SYS_HOME_CONFIG stHomeConfig = new SYS_HOME_CONFIG(); stHomeConfig.wMode = 3; // 原點復歸模式 3 (碰 Home Sensor 減速停止並偏移) stHomeConfig.wDirection = 0; // 起始搜尋方向：0=正方向, 1=負方向 stHomeConfig.wSensorMode = MCCL.SL_NORMAL_OPEN; // 開關配線方式：常開 (Active High) 或 常閉 (Active Low) stHomeConfig.nIndexCount = 0; // 指定編碼器 Index (Z相) 零位脈波訊號編號 stHomeConfig.dfAccTime = 300; // 加速時間 (ms) stHomeConfig.dfDecTime = 300; // 減速時間 (ms) stHomeConfig.dfHighSpeed = 15.0; // 第一階段高速尋找速度 (mm/sec) stHomeConfig.dfLowSpeed = 2.0; // 第二階段碰觸低速爬行速度 (mm/sec) stHomeConfig.dfOffset = 5.5; // 機械原點至邏輯原點的補償偏移量 (mm) // 對每個通道設定專屬的原點補償 nRet = MCCL.MCC_SetHomeConfig(ref stHomeConfig, 0, MCCL.CARDINDEX0);
4

Step 4：設定運動群組 (Multi-Axis Group Creation)

多軸同動綁定

將各自獨立的物理馬達通道 (Channels) 綁定為一個「同動群組 (Group)」。例如大銀機台之 X-Y-Z-Θ 四軸龍門，必須綁入同一個 Group 才能執行直線與圓弧軌跡插補：

// 建立新群組前，務必先關閉系統中所有現存群組 MCCL.MCC_CloseAllGroups(); // 建立群組：指定 X, Y, Z, U, V, W 對應之實體輸出通道 (-1 代表無該軸) nRet = MCCL.MCC_CreateGroup( 0, // Group X 軸 -> 實體輸出 Channel 0 1, // Group Y 軸 -> 實體輸出 Channel 1 2, // Group Z 軸 -> 實體輸出 Channel 2 3, // Group U 軸 (Θ旋轉) -> 實體輸出 Channel 3 -1, // Group V 軸 (未使用設為 -1) -1, // Group W 軸 (未使用設為 -1) MCCL.CARDINDEX0, // 對應軸卡編號 (Card Index 0) MCCL.COMMAND_QUEUE_SIZE// 系統命令佇列緩衝區深度 );
5

Step 5：設定系統參數與插值時間 (Interpolation Time)

軌跡離散時間調優

初始化系統底層驅動與通訊中斷，並設定核心插值時間 (Interpolation Time)。數值介於 1 ms ~ 50 ms（建議值為 5 ms）。插值時間越短，軌跡越平滑、輪廓誤差越小，但會提高 PC CPU 運算負載：

SYS_CARD_CONFIG stCardConfig = new SYS_CARD_CONFIG(); stCardConfig.wCardAddress = 0x240; // 基礎位址 (PCI 卡自動配置，可保留預設) stCardConfig.wIRQ_No = 5; // 中斷號 IRQ stCardConfig.wCardType = (ushort)EPCIO_CARD_TYPE.EPCIO_4_AXIS_PCI_CARD; // 2: 四軸 PCI 運動卡 // 初始化系統：設定 5ms 插補週期，註冊 1 張控制卡 nRet = MCCL.MCC_InitSystem( 5, // 插值時間 Interpolation Time = 5 ms ref stCardConfig, // 軸卡組態結構 1 // 運動控制卡使用張數 = 1 );
6

Step 6：運動控制設定 (單位、座標系、加減速與 P Gain)

閉迴路比例增益

設定座標系統（公制 mm、絕對座標/增量座標）、進給速度、加減速時間，以及位置閉迴路控制的比例增益 (P Gain)，消除穩態誤差：

// 1. 設定工程單位為公釐 (mm) MCCL.MCC_SetUnit(MCCL.UNIT_MM, MCCL.GROUPINDEX0); // 2. 設定為絕對座標模式 (Absolute Coordinates，如同 CNC G90) MCCL.MCC_SetAbsolute(MCCL.GROUPINDEX0); // 3. 設定直線與圓弧同動時的加速與減速時間 (毫秒) MCCL.MCC_SetAccTime(300, MCCL.GROUPINDEX0); // 300 ms 加速至目標進給速度 MCCL.MCC_SetDecTime(300, MCCL.GROUPINDEX0); // 300 ms 減速至停止 // 4. 設定穩定運行進給速度 (Feed Speed) MCCL.MCC_SetFeedSpeed(30.0, MCCL.GROUPINDEX0); // 30 mm/sec // 5. 設定位置閉迴路比例增益 P Gain (範圍 1 ~ 16256，建議值 60) MCCL.MCC_SetPGain(60, 60, 60, 60, 60, 60, MCCL.CARDINDEX0);
7

Step 7：啟動伺服激磁 (Servo-On) 與軌跡插補運動指令

同動插補與吋動

通電致能各軸馬達伺服 (Servo-On)，並執行直線補間 (Linear Interpolation)、圓弧補間 (Circular) 或吋動定位 (Jog)：

// 1. 開啟伺服馬達激磁 (各 Channel Servo-On) MCCL.MCC_SetServoOn(0, MCCL.CARDINDEX0); // X 軸 MCCL.MCC_SetServoOn(1, MCCL.CARDINDEX0); // Y 軸 MCCL.MCC_SetServoOn(2, MCCL.CARDINDEX0); // Z 軸 MCCL.MCC_SetServoOn(3, MCCL.CARDINDEX0); // Θ 軸 // 2. 吋動操作：微動脈衝 (JogPulse)、步進吋動 (JogSpace) 與連續吋動 (JogConti) MCCL.MCC_JogPulse(100, 0, MCCL.GROUPINDEX0); // X軸前進 100 pulses (微調對準) MCCL.MCC_JogSpace(10.0, 50, 1, MCCL.GROUPINDEX0); // Y軸以 50% 速度前進 10.0 mm MCCL.MCC_JogConti(1, 20, 2, MCCL.GROUPINDEX0); // Z軸以 20% 速度連續負向吋動 (手動面板操作) // 3. 四軸多軸直線插補同動 (Linear Interpolation) // 同時將機台移動至 X=120.0, Y=85.0, Z=-15.0, U=90.0° MCCL.MCC_Line(120.0, 85.0, -15.0, 90.0, 0, 0, 0, MCCL.GROUPINDEX0); // 4. 平面圓弧插補 (Arc Interpolation) // 在 XY 平面內，通過終點與指定圓心座標進行圓弧軌跡運動 MCCL.MCC_ArcTheta(150.0, 85.0, 15.0, MCCL.GROUPINDEX0);

運動控制計量心法：解析度、精度、重複性與背隙補償 (Backlash)

解析度、精密度與準確度

  • 解析度 (Resolution)：編碼器能感測到的最小步進位移量（如 17-bit = 131,072 pulses/rev）。
  • 精密度 / 準確度 (Accuracy)：目標真值與測量值之間的接近程度。不與雷射干涉儀標準校正，精度就無從談起。
  • 可重複性 (Repeatability)：在同一條件下，重複定位於同一點時結果的極端散佈程度。工廠往往更重視重複精度，因為具備可重複性的誤差可以透過軟體補償消除！

齒輪背隙與螺桿間隙補償

傳動滾珠螺桿或減速機齒輪換向時，因物理齒間隙產生無效行程誤差 (Backlash)。MCCL 支援在換向瞬間由軸卡額外多送出若干補償脈衝：

// 設定各軸換向背隙補償量 (單位: pulse 或 mm) MCCL.MCC_SetBacklash( 0.012, // X 軸換向補償 0.012 mm 0.015, // Y 軸換向補償 0.015 mm 0.005, // Z 軸換向補償 0.005 mm 0.0, // Θ 軸 MCCL.GROUPINDEX0 );

六個標準差 (6σ) 與 Cpk 製程能力

當機械手臂重複取放數千次工件時，關鍵尺寸分佈必須符合常態分佈：

  • 6σ 品質水準：百萬次運作中僅允許 3.4 次不良 (Defects Per Million)。
  • Cpk ≥ 1.33：代表機台綜合精度與散布穩定度足以滿足高科技半導體與車用電子生產線！
