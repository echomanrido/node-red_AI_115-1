sc config http start= disabled
網路通訊協定原理補充 (Slide 76~79)：
連接埠 (Port) 是網路 OSI 七層架構中傳輸層 (第四層，Transport Layer) 的核心概念。只有 TCP 或 UDP 通訊協定才有 Port 的概念。常見工控與 Web 埠號包括：HTTP (80)、HTTPS (443)、MySQL (3306)、Modbus TCP (502)、Node-RED (1880)。在命令提示字元中可使用 netstat -ano 列出所有當前占用 Port 的 PID 清單。

九、國手技能競賽級：兩階段巢狀子查詢 (Subquery) 實戰

在第 53 屆全國技能競賽「工業 4.0」項目中，一筆訂單常包含多件不同規格的工件。若直接簡單 SUM 會造成關聯數據混亂，因此必須採用標準的兩階段巢狀子查詢：

競賽試題指定語句：全廠待生產工件總量 (Pending Total) 
SELECT SUM(total_quantity) AS grand_total_quantity FROM (
    SELECT 
        oc_order.order_id, 
        oc_order.order_status_id, 
        SUM(oc_order_product.quantity) AS total_quantity 
    FROM oc_order 
    LEFT JOIN oc_order_product ON oc_order.order_id = oc_order_product.order_id 
    WHERE oc_order.order_status_id < '5' 
    GROUP BY oc_order.order_id, oc_order.order_status_id
) AS subquery;
解構運作原理：
1. 內層子查詢 (subquery)：先依照 order_id 分組加總出每筆待產訂單各自的工件數量 (排除 status 5 完工與 7 取消)。
2. 外層主查詢：將內層計算出的各訂單數量再次 SUM() 加總，得出全廠精確的待加工工件總件數！
競賽試題指定語句：全廠已完工工件總量 (Complete Total) 
SELECT SUM(total_quantity) AS grand_total_quantity FROM (
    SELECT 
        oc_order.order_id, 
        oc_order.order_status_id, 
        SUM(oc_order_product.quantity) AS total_quantity 
    FROM oc_order 
    LEFT JOIN oc_order_product ON oc_order.order_id = oc_order_product.order_id 
    WHERE oc_order.order_status_id = '5' 
    GROUP BY oc_order.order_id, oc_order.order_status_id
) AS subquery;

主題三學習檢核成果

  • ✅ 掌握 SELECT、WHERE、UPDATE、INSERT INTO 等 DDL/DML 基礎語法。
  • ✅ 深刻理解 UPDATE 語法中加上 WHERE 條件的重要性。
  • ✅ 掌握 LEFT JOIN 跨表關聯機制，串聯訂單主表與工件明細表。
  • ✅ 掌握 SUM()、COUNT()、GROUP BY、ORDER BY 與 LIMIT 資料彙整技巧。
  • ✅ 能夠獨立撰寫兩階段巢狀子查詢，精準算出全廠待生產與已完工總數量！

-- 待生產工件總件數統計 (外層 SUM 內層分組加總)
SELECT SUM(total_quantity) AS grand_total_quantity 
FROM (
    SELECT 
        oc_order.order_id, 
        oc_order.order_status_id, 
        SUM(oc_order_product.quantity) AS total_quantity 
    FROM oc_order 
    LEFT JOIN oc_order_product ON oc_order.order_id = oc_order_product.order_id 
    WHERE oc_order.order_status_id < '5' 
    GROUP BY oc_order.order_id, oc_order.order_status_id
) AS subquery;

產線良率動態計算 Function 節點代碼 
let completeCount = flow.get("kpi_complete") || 0;
let defectCount = flow.get("kpi_defects") || 2; // 抽檢不良品件數
let totalProduced = completeCount + defectCount;
let yieldRate = 100.0;

if (totalProduced > 0) {
    yieldRate = ((completeCount / totalProduced) * 100).toFixed(1);
}

msg.payload = parseFloat(yieldRate);
return msg;
