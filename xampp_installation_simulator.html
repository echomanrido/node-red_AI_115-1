Node-RED 與 MySQL 資料庫串接實戰

使用官方 node-red-node-mysql 節點，實現 SCADA 數據自動寫入與歷史查詢。

1. 連線設定檔 (MySQL Connection Config) node-red-node-mysql

在 Node-RED 節點管理中安裝 node-red-node-mysql，並於 MySQL 節點中填入連線參數：

Host: 127.0.0.1 (或 localhost)
Port: 3306
User: root
Password: (留空，XAMPP 預設無密碼)
Database: scada_factory_db
Charset: UTF8_GENERAL_CI
2. Function 節點組裝 INSERT 語法 JavaScript

在 Function 節點中將感測器數據組裝為 SQL 語法，輸出給 MySQL 節點執行寫入： 

// 取得感測器即時數據
const sensor = msg.payload.sensor || "Station_A1";
const temp = msg.payload.temp || 25.8;
const humi = msg.payload.humidity || 60.5;

// 組裝標準 SQL INSERT 語法
msg.topic = `INSERT INTO sensor_logs (sensor_name, temperature, humidity) 
             VALUES ('${sensor}', ${temp}, ${humi})`;

return msg;

常見安裝錯誤與 Port 連接埠衝突排除指南

解決 Apache 啟動失敗 (Port 80/443 被佔用) 與 MySQL 啟動失敗 (Port 3306 衝突) 的標準 SOP。

狀況 1：Apache 啟動報錯 "Port 80 in use by PID..."

原因：Windows 的 IIS 伺服器、World Wide Web 服務或 Skype 佔用了 Port 80。
標準解法 (修改 Apache 連接埠至 8080)：

  1. 點擊 Apache 旁的「Config」➔ 選擇 httpd.conf。
  2. 搜尋 Listen 80 ➔ 修改為 Listen 8080。
  3. 搜尋 ServerName localhost:80 ➔ 修改為 ServerName localhost:8080。
  4. 存檔重啟 Apache，網址改為 http://localhost:8080/phpmyadmin/ 即可！
狀況 2：MySQL 啟動失敗 (Port 3306 被佔用)

原因：電腦先前曾安裝過獨立版 MySQL 服務，開機已自動常駐。
標準解法 (修改 MySQL 連接埠至 3307)：

  1. 點擊 MySQL 旁的「Config」➔ 選擇 my.ini。
  2. 搜尋 port=3306 (共有兩處) ➔ 皆改為 port=3307。
  3. 存檔並啟動 MySQL，Node-RED 連線 Port 同步設定為 3307。
