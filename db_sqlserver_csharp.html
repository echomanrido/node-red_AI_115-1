1 DataTable、DataView 與 DataGrid (DataGridView) 架構比較

DataTable 記憶體資料容器

代表記憶體內的一個關聯式資料表（包含 DataRow 列與 DataColumn 欄）。它獨立於資料庫連線之外，負責在 C# 程式中暫存從 SQL Server 撈取出來的資料，或準備批次寫入的資料。

角色比喻：倉庫裡的「原始貨物清單」
主要操作：新增列 Rows.Add()、定義欄位結構
DataView 動態檢視與篩選器

建立在 DataTable 之上的自訂檢視。不複製資料本身，而是提供動態排序 (Sort)、條件過濾 (RowFilter) 與搜尋功能，常作為 UI 綁定的中介層。

角色比喻：套用了「排序與篩選條件」的放大鏡
主要操作：dv.RowFilter = "Price > 25"
DataGridView WinForms 視覺化控制項

Windows Forms 畫面上的表格 UI 元件（早期稱為 DataGrid）。透過設定 DataSource 屬性綁定 DataTable 或 DataView，將資料呈現給使用者查詢或直接編輯。

角色比喻：展示給客戶看的「數位櫥窗表格」
主要操作：dataGridView1.DataSource = dt;

C# 實作程式碼範例（對應投影片主題與 Machine 資料表）

連線說明：對應投影片中建立的伺服器 localhost\SQLEXPRESS、資料庫 lucky20230805 與帳號 lucky。 
using System;
using System.Data;
using System.Data.SqlClient;
using System.Windows.Forms;

namespace SqlServerCSharpDemo
{
    public partial class Form1 : Form
    {
        // 設定連接字串：對應投影片中的 SQLEXPRESS、資料庫 lucky20230805 與使用者 lucky
        private string connectionString = @"Server=localhost\SQLEXPRESS;Database=lucky20230805;User Id=lucky;Password=your_password;";

        // 【功能 1】使用 C# 連接 SQL Server 並透過 DataGridView 查詢資料
        private void btnQuery_Click(object sender, EventArgs e)
        {
            string query = "SELECT ID, No, DateTime, Coin, Stuf, Price FROM dbo.Machine ORDER BY ID ASC";

            try
            {
                using (SqlConnection conn = new SqlConnection(connectionString))
                {
                    conn.Open();
                    // 使用 SqlDataAdapter 將查詢結果填入 DataTable
                    using (SqlDataAdapter adapter = new SqlDataAdapter(query, conn))
                    {
                        DataTable dt = new DataTable("Machine");
                        adapter.Fill(dt);

                        // 將 DataTable 綁定至畫面上的 DataGridView 控制項
                        dataGridView1.DataSource = dt;
                    }
                }
            }
            catch (Exception ex)
            {
                MessageBox.Show("資料庫查詢失敗：" + ex.Message);
            }
        }
    }
}
安全插入資料：使用參數化查詢 (SqlCommand.Parameters) 將機台資料寫入 dbo.Machine 並刷新 DataGridView。 
// 【功能 2】插入資料至 SQL Server 並同步更新 DataGridView
private void btnInsert_Click(object sender, EventArgs e)
{
    string insertSql = @"INSERT INTO dbo.Machine (ID, No, DateTime, Coin, Stuf, Price) 
                         VALUES (@ID, @No, @DateTime, @Coin, @Stuf, @Price)";

    try
    {
        using (SqlConnection conn = new SqlConnection(connectionString))
        {
            conn.Open();
            using (SqlCommand cmd = new SqlCommand(insertSql, conn))
            {
                // 使用參數化避免 SQL Injection，對應 Machine 資料表欄位型別
                cmd.Parameters.AddWithValue("@ID", int.Parse(txtID.Text));
                cmd.Parameters.AddWithValue("@No", int.Parse(txtNo.Text));
                cmd.Parameters.AddWithValue("@DateTime", DateTime.Now);
                cmd.Parameters.AddWithValue("@Coin", int.Parse(txtCoin.Text));
                cmd.Parameters.AddWithValue("@Stuf", int.Parse(txtStuf.Text));
                cmd.Parameters.AddWithValue("@Price", decimal.Parse(txtPrice.Text));

                int rowsAffected = cmd.ExecuteNonQuery();
                if (rowsAffected > 0)
                {
                    // 插入成功後重新執行查詢，讓 DataGridView 顯示最新資料
                    btnQuery_Click(null, null);
                }
            }
        }
    }
    catch (Exception ex)
    {
        MessageBox.Show("插入資料失敗：" + ex.Message);
    }
}
記憶體資料操作：建立 DataTable 並透過 DataView 進行即時排序與篩選，無須重複查詢資料庫。 
// 【功能 3】DataTable 建立與 DataView 排序篩選應用
private void FilterWithDataView(DataTable machineTable)
{
    // 1. 直接從現有的 DataTable 建立 DataView
    DataView dv = new DataView(machineTable);

    // 2. 設定篩選條件 (例如：只顯示投幣數 Coin > 100 的機台紀錄)
    dv.RowFilter = "Coin > 100";

    // 3. 設定排序方式 (依 ID 遞減排序)
    dv.Sort = "ID DESC";

    // 4. 將篩選後的 DataView 綁定給 DataGridView 顯示
    dataGridView1.DataSource = dv;
}

為什麼會發生「時間多 8 小時」問題？（投影片 P.12 - P.14 重點解析）

當我們在 SQL Server 儲存 2023-08-05 00:00:00.000（型別為 datetime，不含時區資訊）時，Grafana 預設會將資料庫撈出來的時間視為 UTC 標準時間，接著又根據瀏覽器預設時區（Taiwan, CST UTC+08:00）自動幫它加上 8 小時，導致看板上變成 2023-08-05 08:00:00（或是 22:00 變成隔天 06:00）！

解決步驟 1 (P.14)： 點擊看板右上角齒輪圖示 Dashboard settings 解決步驟 2 (P.13)： 於 General ➔ Time options 將 Time zone 改為 Coordinated Universal Time (UTC)
