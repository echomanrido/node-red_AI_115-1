本機私有 RAG 知識庫搭建實戰

核心精髓

什麼是 RAG (檢索增強生成)？

當我們要 LLM 回答內部機密檔案（如：114年機電自控學員名單）時，模型並未學習過該內容。RAG 透過「Embedding 嵌入向量模型」將文字切塊並存入本機向量庫，在發問時先檢索相關內文再一併餵給大模型總結，精準無幻覺！

Ollama REST API 互動測試主控台

執行模式：

您可以在此直接編輯 JSON Payload 請求主體，點擊「發送請求」將即時向本機 Ollama 進行通訊測試！預設模型已設定為投影片範例的 gemma4:e4b。若連線失敗，系統將自動啟動除錯引導並提供 CORS 解決方案。

為什麼直接開網頁可以，但這裡發送會錯誤？(瀏覽器 CORS 跨域同源策略)

現象解釋：直接在瀏覽器輸入 http://localhost:11434/api/tags 屬於頂層導航，瀏覽器不會限制。但是在網頁中透過 JavaScript 的 fetch() 發出請求時，瀏覽器會強制檢查 CORS 安全標頭。若本機 Ollama 尚未設定開放跨域，瀏覽器就會自動攔截並回傳 Failed to fetch。

// 徹底讓網頁能夠直接 Fetch 的設定方法 (Windows PowerShell 管理員執行)：

[System.Environment]::SetEnvironmentVariable('OLLAMA_ORIGINS', '*', 'User')

執行後至 Windows 右下角工作列將 Ollama「Quit」關閉重啟即可生效！

關鍵 JSON 屬性說明
  • response：模型生成的回答純文字，包含 markdown 粗體符號（如 **五股...**）。
  • stream: false：若設置為 false，代表關閉 SSE 串流，等待模型全部運算完成後以單一 JSON 物件整體返回。
  • context：投影片中一長串數字數組（如 105, 2364, 107...）。此為本次對話轉譯後的 Token ID 列表。下次發送請求時若附帶此 context 陣列，Ollama 即可擁有前次對話的短期記憶！
前端開發 CORS 跨域避坑提醒

投影片中自建客戶端（localhost:5173）能成功呼叫，是因為 Ollama 回應標頭已自帶 Access-Control-Allow-Origin: *。若在生產環境遇到跨域問題，可設定環境變數 OLLAMA_ORIGINS="*" 解決。

Ollama 常用 REST API 端點速查

方法 Endpoint 主要用途 範例 Payload 摘要

總結回顧：投影片核心考點與實戰要點

模組 / 功能 關鍵操作 / 建議值 重要特性與注意事項
Ollama 模型下載 ollama run <model> 遇到 412 錯誤代表 Ollama 版本過舊，需重新安裝官網更新檔。
Context Length 調大至 16k ~ 256k 電腦記憶體 (RAM/VRAM) 足夠時盡量拉滿，避免對話截斷記憶丟失。
Page Assist Chrome Web Store 外掛 提供直覺聊天界面、支援提示詞範本，可隨時側邊欄懸浮呼叫。
本機 RAG 向量 embeddinggemma 需配合 14B~27B 以上的大參數模型才能完整提取名單或表格內容。
REST API :11434/api/generate 預設開放於 11434 埠，傳遞 stream: false 可取得完整 JSON 回傳。
