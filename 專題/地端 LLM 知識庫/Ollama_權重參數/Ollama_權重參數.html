CHAPTER 03 · NEURAL NETWORK WEIGHTS

如何讀取「模型訓練出來的參數（權重）」？

模型訓練學到的數十億個參數（Weights 與 Biases），全部以二進位張量（Tensors）形式封裝在 GGUF 格式 的最大檔案中。因為經過量化壓縮，直接用記事本打開會是亂碼，需透過 Python 讀取。

📦 最大 Blob 檔案（GGUF 格式）內部構造解析

1. Magic & Version
檔案識別標頭
("GGUF")
2. Metadata KV Pairs
模型架構參數
(層數、維度、詞彙表)
3. Tensor Data (佔 99.9% 檔案大小 · 訓練權重本體)
token_embd.weight attn_qkv.weight ffn_up/gate/down
1.py — 讀取 GGUF 模型訓練權重與數值（語法高亮版）
先安裝: pip install gguf numpy 下載 看參數.py 
from gguf import GGUFReader
import numpy as np

# 1. 填入你 blobs 資料夾中對應模型的最大檔案路徑
# 範例：267,862 KB 的檔案 (sha256-970aa74c0a90ef7482477cf803618e776e173c00...)
blob_path = r"C:\Users\echom\.ollama\models\blobs\sha256-970aa74c0a90ef7482477cf803618e776e173c00..."

# 2. 使用記憶體映射 (mmap) 開啟，即使讀取 18 GB 檔案也不會耗盡電腦記憶體
reader = GGUFReader(blob_path, "r")

print(f"總共有 {len(reader.tensors)} 組權重張量 (Tensors)\n")

# 3. 遍歷並印出前 10 組訓練參數（權重層）的名稱、形狀、精度型態與實際數值
for i, tensor in enumerate(reader.tensors[:10]):
    print(f"[{i+1:02d}] 層名稱 (Name): {tensor.name}")
    print(f"     張量形狀 (Shape): {tensor.shape}")
    print(f"     量化類型 (Type): {tensor.tensor_type.name}")
    print(f"     前 5 筆資料: {tensor.data[:5]}")
    print("-" * 60)

為什麼總共是 112 組張量？（架構反推公式）

從你的輸出維度（隱藏層 768、詞彙量 30522、SwiGLU 門控結構）可精準反推這是標準的 12 層 Transformer Encoder（如 nomic-embed-text）：

  • • 輸入嵌入層：4 組 (embd + types + norm.w/b)
  • • 12 層區塊：12 × 9 組 = 108 組 (attn + ffn + norm)
  • • 總計：4 + 108 = 112 組權重張量 (Tensors)
