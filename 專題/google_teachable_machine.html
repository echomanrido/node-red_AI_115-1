機器學習核心：模型複雜度與預測誤差曲線

在進入 Teachable Machine 實作之前，必須先理解「訓練集 (Training Set)」與「測試集/驗證集 (Test Set)」在不同模型複雜度下的行為差異，這是後續分析訓練成敗的理論核心。

模型複雜度與誤差變化圖 (參考馬維銘教授講義模型) 最佳平衡點：乙區

甲區：配適不足 (Underfitting)

模型過於單純，特徵提取能力太差。特徵是訓練集與測試集誤差皆偏高，無論丟什麼圖片都無法有效區分。

乙區：理想平衡 (Best Generalization)

測試集誤差降至最低谷，模型學會了真實世界的共用規律（泛化能力強），而非單純死記硬背。

戊區：過度配適 (Overfitting)

模型死記訓練集背景雜訊，訓練集誤差趨近 0，但遇到未見過的測試集誤差大幅回升，無法於實務上使用。

Epochs (訓練週期)

比喻：學生整本課本讀完幾次

所有訓練圖片通過神經網路來回傳遞（一次前向與一次反向傳播）的總遍數。
• 設太小： 欠擬合，還沒學好。
• 設太大： 過度擬合，死記細節。

預設: 16

Batch Size (批次大小)

比喻：一次看幾頁書才寫一次筆記

單次迭代中模型同時計算的一組影像數量。
• 較大批次： 訓練平穩快速，但吃更多記憶體。
• 較小批次： 隨機性強，助於跳脫局部低谷。

預設: 0.001

Learning Rate (學習率)

比喻：每次訂正錯誤的跨步幅度

梯度下降更新內部權重時的步長幅度。
• 步伐太大： 容易跳過最佳解，震盪發散。
• 步伐太小： 收斂極其緩慢，時間成本高。

3. Google Colab 執行 Keras 模型 (.h5) 與 Keras 3 版本相容修復

TensorFlow / Keras 3.x
常見報錯原因： Teachable Machine 匯出的 keras_model.h5 採用舊版 Keras 2 格式，直接在新版 Google Colab (Python 3.12 / Keras 3) 執行 load_model() 會拋出 ValueError: Unrecognized keyword arguments passed to DepthwiseConv2D: {'groups': 1}。透過下方自定義類別即可完美解決： 
import tensorflow as tf
from keras.models import load_model
from PIL import Image, ImageOps
import numpy as np

np.set_printoptions(suppress=True)

# 1. 定義自訂 DepthwiseConv2D 類別，自動過濾新版 Keras 3 不相容的 'groups' 參數
class CustomDepthwiseConv2D(tf.keras.layers.DepthwiseConv2D):
    def __init__(self, **kwargs):
        if 'groups' in kwargs:
            del kwargs['groups']
        super().__init__(**kwargs)

# 2. 透過 custom_object_scope 載入模型與標籤檔
with tf.keras.utils.custom_object_scope({'DepthwiseConv2D': CustomDepthwiseConv2D}):
    model = load_model("/content/teachableMachine/keras_model.h5", compile=False)

class_names = open("/content/teachableMachine/labels.txt", "r").readlines()

# 3. 影像預處理 (縮放裁切為 224x224 並正規化至 [-1, 1])
data = np.ndarray(shape=(1, 224, 224, 3), dtype=np.float32)
image = Image.open("/content/jpg/Black.jpg").convert("RGB")
image = ImageOps.fit(image, (224, 224), Image.Resampling.LANCZOS)
normalized_image_array = (np.asarray(image).astype(np.float32) / 127.5) - 1
data[0] = normalized_image_array

# 4. 執行模型推論並輸出結果
prediction = model.predict(data)
index = np.argmax(prediction)
print("Class:", class_names[index][2:].strip())
print("Confidence Score:", prediction[0][index])

底層核心技術深度剖析與架構對比：Teachable Machine vs. YOLO

在視覺與多模態 AI 專案選型時，最常面臨「影像分類 / 時序識別」與「即時物件偵測」的抉擇。以下完整拆解 Google Teachable Machine（涵蓋 MobileNet 卷積原理、遷移學習微調、FFT 聲學頻譜、RNN 循環神經網路與 PoseNet 骨架偵測）以及 YOLO 系列背後的神經網路核心技術。

MobileNet 輕量視覺 RNN / FFT 時序聲學 PoseNet 關節骨架

1. Google Teachable Machine 核心技術深度解析

Engine: TensorFlow.js + WebGL GPU

Google Teachable Machine 之所以能在沒有獨立顯示卡的普通筆電瀏覽器上，僅花 10~30 秒就完成 AI 模型訓練，關鍵在於它結合了「預訓練骨幹網路 (Pre-trained Backbone) + 遷移學習微調 (Transfer Learning)」架構。它將繁重的底層特徵提取交給 Google 預先在數百萬筆資料上訓練好的神經網路，並凍結其權重，僅針對使用者新增的分類標籤訓練最後一層輕量級分類器。

核心關鍵：CNN（卷積神經網路）與遷移學習雙引擎如何運作？

Pre-trained CNN + Transfer Learning

Teachable Machine 確實有使用到 CNN（卷積神經網路），而且正是它能快速訓練出高準確率模型的核心關鍵！它的底層運作方式巧妙結合了 CNN 特徵提取 與 遷移學習（Transfer Learning） 兩大機制：

CNN 卷積特徵提取器（凍結） ➔ 自訂全連接分類器（微調）運作示意圖
1 底層架構（CNN 特徵提取器）

在處理圖片與音訊專案時，Teachable Machine 並不是從零開始訓練一個全新的神經網路。它直接內建了 Google 預先訓練好的輕量級 CNN 模型（例如 MobileNet）作為「特徵提取器（Feature Extractor）」，負責辨識影像中的線條、形狀、紋理等基礎視覺特徵。

2 你的訓練過程（自訂分類器）

當你在網頁上上傳照片並按下「訓練模型」時，系統會凍結原本 CNN 模型的權重，只針對最後一層的全連接層（Dense / Classification Layer）進行訓練。這層網路會根據 CNN 提取出來的特徵，學習如何將它們對應到你設定的分類標籤（例如「貓」或「狗」）。

3 為什麼這樣設計？

透過「預訓練 CNN + 遷移學習」的架構，你不需要準備數十萬張照片，也不需要強大的 GPU 伺服器，只要幾十張範例照片，就能在幾秒鐘內於一般瀏覽器上完成訓練並獲得極高準確率。

圖解 A：Teachable Machine 多模態遷移學習與微調管線 (Pipeline) Frozen Backbone + Trainable Custom Head

1. MobileNet 深度可分離卷積

計算量減少 8~9 倍

傳統卷積神經網路（如 VGG、ResNet）在計算時將「空間濾波」與「通道融合」綁在一起，參數量極其龐大。Google 提出的 MobileNet 將標準卷積拆解為兩道輕量化步驟，使模型體積縮小至僅約 5 MB，在瀏覽器中即可達到 30+ FPS 即時推論：

  • ① Depthwise Convolution (逐通道卷積)：每個色彩通道 (R, G, B) 各自使用獨立的 3×3 卷積核進行空間特徵提取，通道彼此間不混合。
  • ② Pointwise Convolution (1×1 逐點卷積)：接著使用 1×1 卷積核在深度方向上進行線性加權組合，將各通道特徵融合成新的特徵圖。
MobileNet 卷積拆解原理圖 (Depthwise + Pointwise)

2. 遷移學習與微調 (Transfer Learning & Fine-Tuning)

小樣本快速收斂

深度學習模型具有階層式特徵表現能力：淺層網路負責辨識通用的「邊緣、紋理、幾何曲線」，越深層才負責組合成「特定物體」。遷移學習微調正是利用這項特性：

  • 🔒 特徵凍結 (Feature Extraction)：保留 MobileNet 在 ImageNet（1,400 萬張圖片、1,000 類）學到的通用視覺知識，將前面數十層卷積層參數「鎖死」，訓練時不修改它們。
  • 🔥 分類頭微調 (Head Fine-Tuning)：移除原本 1,000 類的輸出層，接上針對你專案的新全連接層（Dense Layer）。透過反向傳播微調這層權重，只需每類 20~50 張照片即可學會全新分類任務。

3. RNN (循環神經網路) 與聲學時序處理

時間序列記憶

影像是靜態空間資料，但聲音專案 (Audio Project) 與連續動作訊號屬於時間序列 (Time-Series) 資料，前後順序決定語意（例如「開燈」與「燈開」）：

  • 🔄 RNN (Recurrent Neural Network) 記憶迴圈：傳統神經網路每次輸入彼此獨立，而 RNN 擁有隱藏狀態 (Hidden State, ht)，會將前一時間點的記憶資訊迴圈傳遞到下一時間點，讓模型具備「上下文短期記憶能力」。
  • 📊 FFT 梅爾頻譜圖 (Spectrogram)：Teachable Machine 先將 1 秒音訊切分為數十個時間窗口，透過快速傅立葉轉換 (FFT) 抽出各頻率能量形成 2D 頻譜圖，再結合卷積與時序特徵提取完成精準語音指令辨識。

4. PoseNet 17 關鍵點骨架估計與抗干擾設計

17 Keypoints 向量

如果直接用一般影像模型訓練「舉左手 / 舉右手」，換穿不同顏色的衣服或換個房間背景就會辨識失敗。姿態專案 (Pose Project) 採用兩階段解耦設計：

  • 🦴 關鍵點座標抽取：底層先執行 PoseNet 捲積網路，從影像中精準定位人體 17 個主要關節座標 (x, y) 與信心度（鼻、雙眼、雙耳、雙肩、雙肘、雙腕、雙髖、雙膝、雙踝）。
  • 🛡️ 徹底濾除背景與衣著雜訊：系統只將這 17 組純幾何骨架向量送入分類頭微調，因此無論背景多雜亂、光線變化或更換服裝，依然能精準辨識動作姿勢。

2. YOLO (You Only Look Once) 核心技術深度解析

Architecture: Backbone + Neck + Decoupled Head

傳統雙階段偵測器（如 R-CNN 系列）需先產生數千個候選框再逐一分類，速度極慢。YOLO（你只需看一次）將物件偵測重新定義為單一迴歸問題，只需將整張影像送入神經網路一次前向傳播，就能同時預測出畫面中所有物體的類別機率與精準的邊界框座標 (x, y, w, h)。

圖解 B：現代 YOLO (v8 / v11) 完整三段式偵測管線與 NMS 後處理 Input → Backbone → Neck → Head → NMS

1. 網格劃分與 Anchor-Free 座標迴歸

YOLO 將輸入畫面切分為多個網格（如 80×80、40×40、20×20 三種尺度），物體中心點落入哪個網格，就由該網格負責預測。現代 YOLOv8 / v11 更摒棄了傳統繁瑣的預設錨框 (Anchor-Based)，改採 Anchor-Free 直接預測目標中心點到邊界框四條邊的距離 (l, t, r, b)，大幅提升對不規則形狀物體的泛化能力。

2. FPN + PANet 雙向特徵金字塔融合

卷積網路越深，語意理解越強（知道是貓），但空間座標越模糊；越淺則位置越精準但看不懂語意。YOLO 在 Neck 層結合：
• FPN (自頂向下)：將深層強語意特徵上採樣傳遞給淺層。
• PANet (自底向上)：將淺層精準邊緣位置資訊再往深層回傳。
雙向融合使模型同時具備「看得懂」與「框得準」的能力。

3. IoU 交併比與 NMS (非極大值抑制)

同一顆紅圓周圍的相鄰網格可能會同時預測出 5~10 個重疊的邊界框。YOLO 透過後處理演算法精準去重：
• IoU (Intersection over Union)：計算兩個預測框「交集面積 ÷ 聯集面積」的重疊率。
• NMS 機制：先選出信心分數最高（如 0.99）的框作為基準，將與其 IoU 超過門檻（如 > 0.45）的重複框全數刪除，確保畫面乾淨不重複標記。

4. Mosaic 資料增強與 CIoU 損失函數

• Mosaic 馬賽克增強：訓練時隨機將 4 張不同圖片縮放拼接成 1 張，迫使模型在複雜背景與局部遮擋下學會辨識小物體。
• CIoU / DFL 損失函數：不僅計算預測框與真實標註框的重疊面積，還同時懲罰「中心點距離偏差」與「長寬比差異」，讓邊界框收斂得更快、更貼合物體輪廓。
