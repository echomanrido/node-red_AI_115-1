機器學習核心：模型複雜度與預測誤差曲線

在進入 Teachable Machine 實作之前，必須先理解「訓練集 (Training Set)」與「測試集/驗證集 (Test Set)」在不同模型複雜度下的行為差異，這是後續分析訓練成敗的理論核心。

模型複雜度與誤差變化圖 (參考馬維銘教授講義模型) 最佳平衡點：乙區

甲區：配適不足 (Underfitting)

模型過於單純，特徵提取能力太差。特徵是訓練集與測試集誤差皆偏高，無論丟什麼圖片都無法有效區分。

乙區：理想平衡 (Best Generalization)

測試集誤差降至最低谷，模型學會了真實世界的共用規律（泛化能力強），而非單純死記硬背。

戊區：過度配適 (Overfitting)

模型死記訓練集背景雜訊，訓練集誤差趨近 0，但遇到未見過的測試集誤差大幅回升，無法於實務上使用。

Teachable Machine 完整實作流程

Google Teachable Machine 是一套能在瀏覽器端利用 WebGL 加速的遷移學習 (Transfer Learning) 工具。我們以「剪刀、石頭、布」手勢與幾何圖形辨識為例。

Step 1

建立專案

選擇 Standard (224x224 彩色) 或 Embedded (96x96 微控制器) 專案類型。

Step 2

收集樣本

透過 Webcam 連拍、雲端硬碟匯入或本機上傳各分類影像（如布/石頭/剪刀）。

Step 3

模型訓練

點擊 Train Model，瀏覽器本地透過 MobileNet 權重特徵提取進行訓練。

Step 4

預覽與匯出

即時測試信心分數，上傳雲端取得公開模型連結或下載 Keras / TF.js 檔。

Epochs (訓練週期)

比喻：學生整本課本讀完幾次

所有訓練圖片通過神經網路來回傳遞（一次前向與一次反向傳播）的總遍數。
• 設太小： 欠擬合，還沒學好。
• 設太大： 過度擬合，死記細節。

預設: 16

Batch Size (批次大小)

比喻：一次看幾頁書才寫一次筆記

單次迭代中模型同時計算的一組影像數量。
• 較大批次： 訓練平穩快速，但吃更多記憶體。
• 較小批次： 隨機性強，助於跳脫局部低谷。

預設: 0.001

Learning Rate (學習率)

比喻：每次訂正錯誤的跨步幅度

梯度下降更新內部權重時的步長幅度。
• 步伐太大： 容易跳過最佳解，震盪發散。
• 步伐太小： 收斂極其緩慢，時間成本高。

  const URL = "https://teachablemachine.withgoogle.com/models/8PXy27q_0/"; // 你的模型分享網址
  let model, webcam, labelContainer, maxPredictions;

  async function init() {
    const modelURL = URL + "model.json";
    const metadataURL = URL + "metadata.json";
    model = await tmImage.load(modelURL, metadataURL);
    maxPredictions = model.getTotalClasses();

    webcam = new tmImage.Webcam(200, 200, true);
    await webcam.setup();
    await webcam.play();
    window.requestAnimationFrame(loop);

    document.getElementById("webcam-container").appendChild(webcam.canvas);
    labelContainer = document.getElementById("label-container");
    for (let i = 0; i < maxPredictions; i++) {
      labelContainer.appendChild(document.createElement("div"));
    }
  }

  async function loop() {
    webcam.update();
    await predict();
    window.requestAnimationFrame(loop);
  }

  async function predict() {
    const prediction = await model.predict(webcam.canvas);
    for (let i = 0; i < maxPredictions; i++) {
      const classPrediction = prediction[i].className + ": " + prediction[i].probability.toFixed(2);
      labelContainer.childNodes[i].innerHTML = classPrediction;
    }
  }
</script>

3. Google Colab 整合：修復 Keras 3 的 DepthwiseConv2D 錯誤

keras_model.h5 + Colab
錯誤剖析： Teachable Machine 導出的 keras_model.h5 是基於較舊版的 Keras 構建。當在現代 Google Colab (預設升級至 Keras 3 / TensorFlow 2.16+) 中載入時，會噴出經典報錯：
ValueError: Unrecognized keyword arguments passed to DepthwiseConv2D: {'groups': 1}
解決方案是透過自定義 CustomDepthwiseConv2D 繼承類別，在 __init__ 時移除 groups 參數，並使用 custom_object_scope 包裹載入。
可直接於 Colab 運行的完美相容程式碼：
import tensorflow as tf
from keras.models import load_model
from PIL import Image, ImageOps
import numpy as np

# 關閉科學記號以利易讀
np.set_printoptions(suppress=True)

# 解決 Keras 3 / TF 最新版中 DepthwiseConv2D 不支援 groups 參數的相容性錯誤
class CustomDepthwiseConv2D(tf.keras.layers.DepthwiseConv2D):
    def __init__(self, **kwargs):
        if 'groups' in kwargs:
            del kwargs['groups']  # 移除衝突的 groups 參數
        super().__init__(**kwargs)

# 使用 custom_object_scope 載入 Teachable Machine 匯出的 h5 模型
model_path = "/content/teachableMachine/keras_model.h5"
labels_path = "/content/teachableMachine/labels.txt"

with tf.keras.utils.custom_object_scope({'DepthwiseConv2D': CustomDepthwiseConv2D}):
    model = load_model(model_path, compile=False)

# 讀取分類標籤
class_names = open(labels_path, "r", encoding="utf-8").readlines()

# 影像預處理：轉為 224x224 RGB 並做色彩正規化 [-1, 1]
data = np.ndarray(shape=(1, 224, 224, 3), dtype=np.float32)
image = Image.open("/content/test_image.jpg").convert("RGB")
size = (224, 224)
image = ImageOps.fit(image, size, Image.Resampling.LANCZOS)
image_array = np.asarray(image)
normalized_image_array = (image_array.astype(np.float32) / 127.5) - 1
data[0] = normalized_image_array

# 執行預測推論
prediction = model.predict(data)
index = np.argmax(prediction)
class_name = class_names[index].strip()
confidence_score = prediction[0][index]

print(f"🎯 預測類別: {class_name[2:]}")
print(f"📊 信心指數: {confidence_score:.4f}")
