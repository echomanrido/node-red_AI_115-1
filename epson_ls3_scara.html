Epson SCARA Robot Guide

Epson LS3 水平多關節機械手臂操作指南

本教學網頁依據 Epson LS3 機械手臂與 RC90-B 控制器技術手冊及培訓投影片製作。完整涵蓋從環境備份、USB/Ethernet 連線、手動點位示教到 SPEL+ 程式語言控制的核心步驟。

硬體規格 (LS3-401S)

  • 本體重量： 14 kg
  • 最大負載： 3 kg
  • 手臂臂長： J1+J2 = 400 mm
  • Z軸行程： 150 mm
  • 馬達功率： Axis1(200W), Axis2/3/4(100W)

控制器與軟體

  • 控制器： RC90-B 系列控制器
  • 開發軟體： Epson RC+ 7.0 (Ver.7.4.4或更高)
  • 通訊方式： USB 2.0 (免密碼) 或 Ethernet (TCP/IPv4)
  • 作業系統限制： 不支援 IPv6，需使用 IPv4

核心操作 5 步驟

  1. 電腦上確認備份和專案
  2. 連線設定 (透過USB免密碼)
  3. 命令測試 (Reset / Motor On)
  4. 示教機器人點 (Jog & Teach)
  5. 寫程式控制 (SPEL+ 語法)
Step 1

確認備份與專案 (Project & Backup)

在進行任何機器人程式開發前，務必確認出廠配置的機器人數據與專案備份。專案與系統配置的完整備份流程如下：

專案複製步驟

    href
  1. 從功能表選擇 [專案 (Project)] -> [複製 (Copy)]。
  2. 變更 [Destination Drive] 至任意磁碟機。
  3. 點擊 <OK>，將專案複製到外部媒體。

控制器系統備份步驟

  1. 從功能表選擇 [工具 (Tools)] -> [控制器 (Controller)]。
  2. 按下 <備份控制器 (Backup Controller)> 按鈕。
  3. 選擇任意磁碟機並點擊 <OK> 完成系統配置備份。
Step 2

連線設定 (PC to Controller Communications)

Epson RC+ 7.0 預設支援透過 USB 2.0 / 1.1 與控制器進行通訊，透過 USB 連線時不需要密碼身份驗證。

詳細連線步驟：

01

硬體連接

使用 USB 線連接開發電腦與控制器的專用 USB 連接埠 (USB B系列接頭)。

02

開啟電源

打開控制器主電源開關。

03

軟體設定

開啟 Epson RC+ 7.0，點選 [設置] -> [電腦與控制器通信]。

04

點擊連接

選擇「No.1 USB」，點擊 <連接>，確認狀態顯示「已連接」後點擊 <關閉>。

Step 3

指令視窗測試 (Command Window Testing)

連線成功後，可透過 [工具 (Tools)] -> [命令窗口 (Command Window)] 執行基礎指令來測試機械手臂狀態。

// 1. 重置控制器狀態
> Reset
// 2. 解除機械臂(#1到#4)的制動器
> Brake Off
// 3. 重新開啟制動器
> Brake On
// 4. 啟動馬達並歸零脈衝位置 (水平多關節機器人)
> Motor On
> Go Pulse (0, 0, 0, 0)
Step 4

示教機器人點 (Robot Manager / Jog & Teach)

透過圖形化介面精準控制手臂位置並記錄點位資料。

  1. 點擊工具列上的 <Robot Manager> 按鈕，開啟控制器面板。
  2. 在狀態頁面確認安全防護(Safeguard)與急停(Emergency Stop)狀態正常。
  3. 點擊 [Jog & Teach] 標籤頁進入手動微調模式。
  4. 使用世界坐標系 (World) 或關節坐標系 (Joint) 的方向按鈕（+X, -X, +Y, -Y 等）移動手臂。
  5. 點擊右下角的 <Teach> 按鈕，即可將當前位置儲存為點位（如 P0, pick, place）。
Step 5
