Ollama 連接設定

需設定 CORS
CMD 跨域 (CORS) 啟動指令：
set OLLAMA_ORIGINS=* && ollama serve
LM Studio CORS 與 Port 設定：
請至 LM Studio 頂部點擊 Server Settings → 將 Enable CORS 切換為開啟 (綠色)，並確保 Server Port 為 1234。
