01

LM Studio 官方下載與簡介

官方網站：https://lmstudio.ai/

LM Studio 是一款專為桌面系統設計的本機大語言模型執行環境，支援 Windows、macOS 與 Linux。最新版本引進 Bionic Agent 功能，提供強大的本地編程與即時預覽能力。

  • 本機執行 (Natively Local)： 模型與資料皆儲存在本地硬碟，不用連上雲端。
  • 支援主流模型格式： 完美相容 HuggingFace GGUF 架構。
  • 內建本機 Agent： 可自動生成網頁、專案管理與修改程式檔。
提醒： 請前往官網下載 Download LM Studio Bionic (x64) 安裝檔並完成安裝。

啟動 Local Server 與伺服器設定 (Server Settings)

將 LM Studio 轉為本機 AI API 伺服器，開放區域網路或 Localhost 存取

07

Model Server 深入解析：Chat with a model & MCP 工具整合

新功能重點

端點：POST /api/v1/chat 搭配 Model Context Protocol (MCP) 與多模態輸入

系統文件截圖：Chat with a model API 規格與 MCP 範例 Developer Docs 實機畫面
彈性的 Input 資料結構

input 欄位支援純字串（String）或包含多模態物件陣列（array<object>）。除了傳送純文字（Text Input）之外，還能直接掛載本機或遠端圖片（Image Input），讓視覺模型（如 Gemma 4 Vision）同時進行圖文問答。

MCP (Model Context Protocol) 整合

透過 integrations 陣列可隨請求掛載外部工具。例如宣告 type: "ephemeral_mcp" 並指向 https://huggingface.co/mcp，模型推論時就能自動動態呼叫 model_search 即時搜尋熱門模型。

外掛 Plugin 瀏覽自動化

支援宣告本機插件（例如 type: "plugin", id: "mcp/playwright"），允許模型運用 browser_navigate 自動操控無頭瀏覽器，前往指定的網頁抓取即時內容，真正達成「本機 Autonomous Agent」能力。

08

實戰整合範例 (Code Snippets)

提供常見呼叫方式，立即在您的專案中介接地端模型

curl http://localhost:1234/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "google/gemma-4-e4b",
    "messages": [
      { "role": "system", "content": "你是一個專業的助理。" },
      { "role": "user", "content": "請用繁體中文自我介紹。" }
    ],
    "temperature": 0.7,
    "stream": false
  }'
# 相容 OpenAI 官方 SDK 寫法
from openai import OpenAI

# 指向本機 LM Studio 伺服器
client = OpenAI(
    base_url="http://localhost:1234/v1",
    api_key="lm-studio" # 本地執行免 API 金鑰
)

response = client.chat.completions.create(
    model="google/gemma-4-e4b",
    messages=[
        {"role": "system", "content": "你是一個具備專業知識的 AI 助手。"},
        {"role": "user", "content": "你好，請簡述地端 LLM 的主要好處！"}
    ],
    temperature=0.7
)

print(response.choices[0].message.content)
// 前端或 Node.js 原生 fetch
async function askLocalLLM() {
  const res = await fetch("http://localhost:1234/v1/chat/completions", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({
      model: "google/gemma-4-e4b",
      messages: [{ role: "user", content: "請簡短問候我！" }],
      temperature: 0.7
    })
  });

  const data = await res.json();
  console.log(data.choices[0].message.content);
}

askLocalLLM();
