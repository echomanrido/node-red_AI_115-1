五大核心子系統深度解析

理論、實作、底層邏輯與工業製造場景完全貫通
實作手冊

1. 核心實驗課程 (34 Labs)

由淺入深的漸進式教學路徑，從最基礎的資料流變換，到工業級 Serial Port、MQTT 與 Modbus 通訊，再到現代 Dashboard 2.0 Vue 3 戰情室建置。

  • 核心五大基礎節點：Inject、Debug、Function、Switch、Change 綜合應用。
  • 工業與物聯網通訊：Serial Port 串口、MQTT 發布/訂閱 Broker、Modbus TCP/RTU 連線。
  • Dashboard 2.0 人機戰情室：指針儀表、多軸折線圖、CSS 主題切換與背景漸層調色。

深度筆記

2. 學習補充教材 (26 篇)

解構軟硬體底層觀念，將機電氣壓元件（電磁閥、雙壓閥、PLC 階梯圖）與程式語法邏輯（if-else、AND、OR）深度對照，並提供商業圖表與前端美學指南。

  • 程式與機電對照：用三口二位電磁閥比喻 if-else，用梭動閥與雙壓閥比喻 OR/AND 邏輯。
  • 數據與圖表選型：直方圖數據分箱 (Bins)、四大長條圖、圓餅環形圖與股票 7 大圖表。
  • Vue 3 主題模擬器：ui-template 萬能節點指南、Base64 編碼原理與本機即時調色盤。

專案實戰

3. 22 大實務專題拆解

完整收錄產線物聯網、金融生活爬蟲、AI 視覺辨識、工業手臂與地端大語言模型 (LLM) 協同作業的 22 個工業 4.0 完整專案。

  • 工業與封包分析：Modbus TCP 連線與 Wireshark 網路抓包十六進位字串深度解析。
  • 生活與金融 API：台銀匯率 Line Bot 告警、氣象預報、台北公車、海域船舶雷達。
  • AI 視覺與手臂：Teachable Machine 影像分類、COCO-SSD 物件偵測、Epson 手臂座標轉換。
  • 大語言模型整合：Gemini 多模態 API、Ollama 車牌辨識、AnythingLLM 私有知識庫 (RAG)。

核心機制

4. Node-RED 底層運作邏輯

深入剖析 Node-RED 為什麼具備極致低延遲與高並發吞吐能力，揭露 Node.js 單執行緒、libuv 異步執行緒池與 WebSocket 通訊架構。

  • 事件循環 (Event Loop)：JavaScript 單執行緒如何靠無阻塞 I/O 同時處理數千感測節點。
  • libuv C/C++ 執行緒池：檔案系統、加解密與網路通訊如何交由底層執行緒背景運算。
  • 全雙工 WebSocket 管線：儀表板數據毫秒級即時推送機制，告別傳統 HTTP 輪詢耗損。

工業 4.0 MES

5. 智慧製造 MES 與電商整合

遵循國家技能競賽工業 4.0 規範，打通 OpenCart 商業電商購物車、MariaDB 資料庫、Node-RED 自動化排程與 C# 上位機的 IT/OT 完整閉環。

  • 訂單驅動生產：客戶下單 ➔ MariaDB 寫入 ➔ Node-RED 提取規格 ➔ CNC 自動加工排程。
  • 工廠 OEE 稼動率：實時計算可用率、效能比與良品率，在大螢幕 SCADA 即時呈現。
  • C# 三大串接方案：方案一 DB 直連、方案二 原生 API、方案三 REST Admin API 微服務。
