什麼是「傳統逆向工程」？

傳統逆向專注於原生二進位碼（Native Code），分析師直接面對 CPU 架構、記憶體分頁、呼叫慣例與未剝離的機械碼。

Native Code（原生代碼） C / C++ / Go / Rust / Delphi

直接編譯為機器碼（ISA 指令）

由編譯鏈直接轉譯為 CPU 的原生機器碼（x86/x64, ARM, MIPS）。函數名、變數型別、結構體在 Release 建置中通常被完全剝離（Stripped），高階控制流（如 switch、for）全數扁平化為條件跳躍指令。

  • ✓ 檔案格式：Windows PE (.exe/.dll), Linux ELF, macOS Mach-O
  • ✓ 逆向難度：高，需依賴反組譯、控制流圖 (CFG) 與型別推斷
  • ✓ 核心工具：Detect It Easy、IDA Pro、Ghidra、x64dbg
Managed Code（受管代碼） Java / C# (.NET) / Android APK

編譯為虛擬機位元組碼（Bytecode）

由中介語言編譯器生成，執行於 JVM 或 .NET CLR。二進位內附帶高度完整的符號表、元資料（Metadata）、類別名稱與方法簽名，只要未深度混淆，通常可近乎 100% 還原出原始高階程式碼。

  • ✓ 檔案格式：.class, .jar, .dex, .dll (IL)
  • ✓ 逆向難度：中等偏低，反編譯工具還原度極高
  • ✓ 代表工具：JADX, dnSpy, ILSpy, CFR

傳統逆向的兩大支柱：靜態分析 vs 動態分析

S

靜態分析（Static Analysis）

不執行目標程式，純粹依據二進位檔案的結構、Header、匯入表、字串常數與反組譯後的控制流圖（CFG）進行邏輯還原。

CFG 控制流圖 Xrefs 交叉引用 Decompiler 虛擬碼 代表：IDA Pro / Ghidra
D

動態分析（Dynamic Analysis）

在受控沙盒或除錯器（Debugger）中執行目標程式，透過設定硬體/軟體斷點、即時觀察暫存器與呼叫堆疊（Call Stack）、記憶體傾印（Memory Dump）。

動態脫殼 (Unpacking) 繞過反除錯 即時抓取記憶體 Key 代表：x64dbg / GDB / WinDbg

三大核心工具深度剖析

TOOL #1 · 偵察與預檢 開源免費 · Horsic 開發

Detect It Easy (DIE) 二進位偵察瑞士刀

在逆向分析的第一分鐘，絕對不要直接把 100MB 的未知執行檔拖進反編譯器。DIE 是逆向工程師的第一道篩選器，它能在數毫秒內判斷檔案架構、編譯鏈、有無加殼以及熵值分布。

編譯器與語言判定

精確識別是由 MSVC、GCC、Clang、Delphi 還是 Go/Rust 編譯。若為 Go 語言，分析者需立即調用專門的 Go 符號恢復腳本。

加殼與混淆偵測

內建豐富的二進位特徵庫，快速標註 UPX、Themida、VMProtect 或自訂 Packer。避免分析者在加殼樁（Stub）中白費功夫。

熵值分析（Entropy Scan）

以 0.0~8.0 的數值衡量每個區段的混亂程度。高熵值（> 7.2）代表此區段高度密碼化或壓縮，極可能藏有 Shellcode。

JavaScript 擴充引擎

支援使用者透過撰寫 JS 腳本添加自訂簽名（Signatures），並能直接檢視 PE/ELF 的 Header、Overlay 與區段偏移。

TOOL #2 · 業界金牌標準 Hex-Rays 出品 · 頂級商業授權

IDA Pro (Interactive DisAssembler) 反編譯之巔

數十年來全球安全機構、漏洞挖掘者與逆向工程師首選的終極武器。以世界第一的靜態控制流圖（CFG）和無可匹敵的 Hex-Rays Decompiler 引擎聞名於世。

Hex-Rays Decompiler (F5 鍵)

將生澀難懂的 x86/x64/ARM 機器碼瞬間轉換為乾淨、結構化的類 C 語言虛擬碼。其型別傳播與常數折疊演算法領先業界。

FLIRT 函式庫快速識別

Fast Library Identification and Recognition Technology 能自動識別數以千計的靜態連結標準庫函數（如 strlen, memcpy），避免重複逆向。

強大的 IDAPython 生態

具備長達 20 年的社群擴充外掛（如 BinDiff 差異對比、FindCrypt 加密特徵提取、ClassInformant RTTI 解析）。

唯一的缺點：授權極昂貴

全套包含 x86/x64/ARM 反編譯模組的授權動輒數千至數萬美元，主要由企業、安全公司與國防軍工單位採購。

IDA Pro 特性快覽 Pro Enterprise
  • 核心語言： C++ (極速原生)
  • 反編譯器： Hex-Rays (業界頂尖)
  • 腳本支援： IDAPython, IDC
  • 資料庫格式： .idb (32位) / .i64 (64位)
  • 跨架構支援： 模組化購買
💡 名言：「在安全界，按 F5 看到 C 代碼是一切快樂的泉源。」
TOOL #3 · 開源巨擘 · NSA 旗艦 Apache 2.0 開源 · 美國國家安全局

Ghidra (吉德拉) 開源軟體逆向工程框架

2019 年由 NSA 在 RSA 大會正式公開釋出。Ghidra 徹底打破了 IDA Pro 長期以來的商業壟斷，為全球安全研究者與學生提供了一個完全免費、自帶多架構反編譯器的 SRE 平台。

原生免費反編譯（全架構）

開箱即支援 x86, ARM, AArch64, MIPS, PowerPC, SPARC, RISC-V 甚至 6502/Z80 等古老晶片，完全零成本。

Sleigh 架構定義語言

使用專屬 DSL 定義處理器語義。若遇到物聯網（IoT）或特殊工業控制晶片，工程師能快速自編模組擴充支援。

原生多人團隊協同（Ghidra Server）

內建版本控制協同伺服器，紅隊或資安團隊能多人同時對同一個二進位進行重命名、加注釋與變數型別同步。

無限制 Undo / Redo

具備完整的步驟復原能力，分析錯誤時只需 Ctrl+Z，極具親和力（早期的 IDA Pro 復原功能較受限）。

Ghidra 特性快覽 Free / Open-Source
  • 開發機構： 美國國家安全局 (NSA)
  • 核心語言： Java + C++ (反編譯引擎)
  • 自訂架構： Sleigh DSL 擴充
  • 團隊協同： 原生內建 Server
  • 社群生態： 蓬勃發展中
🌟 定位：逆向民主化的里程碑，高等院校與安全防護團隊的首選。
