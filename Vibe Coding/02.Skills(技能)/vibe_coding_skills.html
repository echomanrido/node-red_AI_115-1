AI Agent Skills 技能體系
與 MCP 工控整合

從單純文字生成跨越至具備主動工具調用 (Tool Calling) 與專業領域知識的自主代理人。透過 Skills 定義與 MCP (Model Context Protocol)，賦予 AI 操作 PLC、SCADA 與工業資料庫的實體行動能力。

1. 領域知識 Skill 庫

透過 SKILL.md 封裝特定領域規則，例如 MC Protocol 報文解析、Node-RED Flow 規範與 OPC UA 標籤字典。

2. MCP 外部通訊協定

Model Context Protocol 讓 AI 透過標準 RPC 與本地伺服器即時交換工廠設備暫存器、即時曲線與警報日誌，安全不外洩。

3. 自動化測試驗證

結合 subagents 自動運行 Node-RED 語法檢查、C# 單元測試與 Modbus 通訊模擬器，確保生成的控制代碼開箱即用。
