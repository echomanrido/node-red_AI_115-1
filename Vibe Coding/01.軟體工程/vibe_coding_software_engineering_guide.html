Core Philosophy

什麼是 Vibe Coding？

Vibe Coding 並非漫無目的的瞎猜或碰運氣，而是工程思維的高階抽象化：專注於「意圖表達 (Intent)」、「架構規格 (Specs)」與「驗證邊界 (Verification)」，將繁瑣實作交託給 AI 代理。

🗣️

自然語言即編譯器

透過精確的 Prompt、Markdown 規範與上下文注入（Context Engineering），自然語言已晉身為最高階的高階語言。

🔄

自主代理人閉環 (Agentic Loops)

AI 不僅提供補全建議，更能主動呼叫 CLI 工具、自動執行測試、解讀報錯日誌並自主進行迭代修復（Self-Correction）。

🛡️

人機迴圈檢驗 (Human-in-the-Loop)

工程師的精力從語法細節移轉至安全性、系統架構、驗收標準（Acceptance Criteria）與商務邏輯的嚴密驗證。

Paradigm Shift

傳統 SDLC vs. AI-Native SDLC

軟體開發生命週期各階段在引入 Vibe Coding 之後的本質蛻變

開發階段 傳統軟體工程 (Traditional SDLC) Vibe Coding / AI-Native SDLC
需求分析與規格 (Spec) 繁重 PRD 文件、人工討論與容易產生歧義的口語交流。 結構化 Markdown/JSON 規範先行（Spec-driven），直接作為 Agent 的系統上下文。
編碼與實作 (Implementation) 逐行編寫程式碼、查閱 StackOverflow、手動解決配置與樣板。 高階自然語言引導、Agent 多檔案協同生成、百毫秒級原型落地。
測試與驗證 (Testing) 後置撰寫測試案例，容易因為時間緊迫而縮減覆蓋率。 AI 自主生成 TDD 測試矩陣、模擬端到端 (E2E) 行為並自動修補失敗用例。
代碼審查 (Code Review) 逐行檢查語法錯誤、格式規範（Lint）與基本邏輯。 聚焦於業務邏輯正確性、威脅建模、架構健全性與合規安全護欄。
維護與重構 (Maintenance) 懼怕動彈 Legacy Code，技術債隨時間指數增長。 由 Agent 掃描全局相依性，高保真進行跨語言、跨框架重構升級。

Engineering Principles

拒絕通靈：掌握 Vibe Coding 4 大工程柱石

要將「靈感」穩定轉化為生產級軟體，必須建立在嚴謹的工程規範之上。

01 / SPEC-FIRST

規範先決 (Specification)

以 .cursorrules 或 CLAUDE.md 明訂架構、專案依賴與設計邊界。清晰的意圖能降低 AI 幻覺高達 80% 以上。

02 / CONTINUOUS FEEDBACK

自動化驗證閉環

為 Agent 配備 Terminal 與 Linter 工具，讓生成、編譯、單元測試、出錯、自動修補形成無須人手干預的反饋循環。

03 / CONTEXT CURATION

精簡上下文工程

避免將整個程式碼庫一股腦倒入 Prompt。善用代碼地圖 (Repo Maps)、向量檢索與模組化切割，保持模型注意力高度集中。

04 / ARCHITECTURAL REVIEW

審查重心升維

人類工程師不再逐字抓縮排或型別宣告，而是審核資料模型、資安邊界、併發控制與不可逆的商務邏輯變更。
