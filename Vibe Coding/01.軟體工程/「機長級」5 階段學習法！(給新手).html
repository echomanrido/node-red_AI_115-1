概念核心 · 機長思維 (Captain Mindset)

自動駕駛負責飛行，機長負責降落與生死

現代波音與空中巴士可以在巡航時完全由電腦控制。然而，每家航空公司仍花費高昂年薪聘請機長。真正的價值不是在晴空萬里時按下按鈕，而是在發生單發失效、儀表警報、亂流與緊急狀況時，能以秒級反應手動接管系統。

工程師的核心價值：架構設計、邊界條件審查、系統可觀測性（Observability）、與跨領域業務問題的拆解。

資料結構檢索直覺：Array vs HashMap

當資料量為 10 萬筆時，選錯資料結構會讓 AI 寫出的程式從 1 毫秒變成當機 30 秒。 親自動手點擊，體驗線性搜尋 $\mathcal{O}(N)$ 與雜湊常數搜尋 $\mathcal{O}(1)$ 的劇烈差異！

Array (線性連續記憶體) - 時間複雜度 $\mathcal{O}(N)$ 目前比對步數: 0 步
HashMap (雜湊桶映射) - 時間複雜度 $\mathcal{O}(1)$ 雜湊函式 Hash(key) $\to$ 索引
尚未觸發雜湊。點擊「執行 HashMap 雜湊查找」，感受一擊必中的常數級瞬間檢索。
線性搜尋 Array $\mathcal{O}(N)$： 資料量為 $N$ 時，最差需比對 $N$ 次。當 $N=1,000,000$ 筆，伺服器可能耗時數百毫秒甚至超時。
雜湊表 HashMap $\mathcal{O}(1)$： 透過 Hash Function 計算記憶體位址，不論資料有 10 筆或 10 億筆，皆可直奔記憶體位置瞬時讀取。
SQL 資料庫索引 B-Tree $\mathcal{O}(\log N)$： 利用樹狀平衡搜尋，即使有千萬條紀錄，僅需 20 餘次比對即可鎖定資料，這是後端架構的命脈。

Bronze Level

青銅級：痛點自動化腳本

專注解決自己生活中每天發生的真實痛點。不求介面華麗，重視程式與外部環境的互動與穩定排程。

  • 定時爬取指定新聞、即時股價或匯率
  • 串接 Telegram / Discord / Line Bot 推播警報
  • 自動化整理下載資料夾與 Excel 批次處理
學會的核心：Cron 定時任務、HTTP 請求、錯誤重試與環境變數管理。
Silver Level

白銀級：完整前後端全端網站

具有資料庫持久化、用戶登入鑑權、以及狀態管理的生產級 Web 應用系統。

  • 團隊分帳系統或社團活動報名金流機制
  • JWT / OAuth 2.0 登入與會員權限隔離
  • PostgreSQL / MySQL 關聯設計與資料約束
學會的核心：RESTful API 架構、資料庫正規化、前後端跨域與安全授權。
Highest Value
Gold Level

黃金級：AI 垂直領域端到端應用

不只串個簡單的 ChatGPT 聊天框，而是深入特定領域，以自定義知識庫或多 Agent 架構交付高商業價值。

  • 企業專屬 RAG 知識庫問答 (向量資料庫檢索)
  • 結構化 JSON 輸出與自動觸發第三方工作流
  • 垂直行業專用助手 (法規審閱、財務報表比對)
學會的核心：Embedding 向量化、Token 與成本控制、Prompt 工程與評估指標。
