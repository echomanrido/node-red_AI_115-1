步驟 4

關閉預設自動回應訊息

避免官方帳號一直跳出「感謝您的訊息，我們無法個別回覆...」干擾機器人運作

新手最常漏掉！

剛建立的 LINE 官方帳號預設會開啟「罐頭自動回應」。如果不關閉，當使用者傳訊息給您的機器人時，除了您的程式會回覆外，LINE 也會同時跳出一則預設罐頭訊息。請回到 LINE Official Account Manager（或從 Developers Console 點選「回應設定」連結）調整以下設定：

設定項目 (位於：設定 > 回應設定) 建議狀態 原因說明
回應模式 (Response mode) 聊天機器人 (Bot) 或 聊天 純 API 串接選「聊天機器人」；若需真人客服與機器人並存可開啟手動聊天。
自動回應訊息 (Auto-response) 停用 (Disabled) 必關！否則每次使用者發言都會收到系統預設的罐頭回覆。
加入好友歡迎訊息 (Greeting message) 依需求停用或保留 若您的程式會監聽 `follow` 事件自訂歡迎詞，建議設為「停用」。
Webhook 啟用 (Enabled) 必開！確保使用者的訊息能即時傳送到您的 Webhook URL。

常見問題排解 (Troubleshooting)

Q1. 按下 Webhook 的 Verify 出現錯誤？

請確認：(1) 網址必須是 `https://` 開頭且具合法 SSL 憑證（本機開發可使用 ngrok 或 Cloudflare Tunnel）；(2) 您的端點必須接收 `POST` 請求並回傳 HTTP 狀態碼 `200 OK`。

Q2. 為什麼在 LINE Developers Console 找不到「新增 Messaging API Channel」按鈕？

LINE 已更新建立流程！現在無法直接從 Developers Console 建立新的 Messaging API Channel，必須先從步驟 1 的 LINE Official Account Manager 建立官方帳號，再從後台設定啟用。
