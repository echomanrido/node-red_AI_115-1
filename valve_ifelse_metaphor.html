如果程式是靈魂，電磁閥就是骨肉

程式中的 if-else 是一分為二的二元決策； 在氣動工業中，常閉型三口二位電磁閥（3/2-Way NC Solenoid Valve）正是用物理閥芯與彈簧，將這段邏輯完美實體化的硬體存在。

硬體物理運作剖面示意
線圈斷電 (FALSE)
當前狀態： ELSE 區塊生效中（常閉斷電，P口截止，A經R口洩壓）
P口: 封閉
control_logic.c
即時追蹤
if (線圈通電 == false) {
// 閥芯向右吸合：打開進氣路徑
氣流從 P 口導向 A 口; // 氣缸推進
} else {
// 預設/斷電狀態：機械彈簧復位
關閉 P 口，A 口導向 R 口; // 排氣洩壓退回
}

二元決策對比表

IF (True) 支

線圈激磁產生吸力，壓縮彈簧換向。P $\rightarrow$ A 供氣推出負載。

ELSE (False) 支

線圈斷電，彈簧自動推回閥芯。P口封鎖，A $\rightarrow$ R 洩壓歸位。

三大核心工程特性的深度映射

從物理世界到數位邏輯的等價轉換

01

二位性 = 互斥邏輯

電磁閥只有「兩個工作位置（2 Positions）」，閥芯在物理上不可能同時處於左邊與右邊。這完全對應了 if 與 else 絕不同時執行的互斥性。

02

機械彈簧 = Default 兜底

彈簧提供物理上的「預設值（Default State）」。一旦斷電或邏輯條件不成立（`false`），彈簧必然將系統拉回安全排氣狀態，杜絕未定義行為。

03

弱電訊號控強大做功

判斷式本身（線圈電壓）消耗的能量極小，但切換後導通的 P 口高壓氣體卻能推動數百公斤的重物。體現了「軟體邏輯指揮物理做功」的本質。
