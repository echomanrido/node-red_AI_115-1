OpenCart 安裝常見問題與避坑指南

解決 config.php 未改名、install 目錄安全警報與 Storage 目錄保護技巧。

1. 為何安裝時提示「config.php is not writable」？

原因：OpenCart 原始碼預設檔名為 config-dist.php 與 admin/config-dist.php。
解法：手動將這兩個檔案改名為 config.php 即可順暢通過 Step 2 檢測。

2. 安裝完成後後台跳出紅字資安警告？

原因：若未刪除 install 安裝引導目錄，任何人都可以重新執行安裝覆蓋資料庫。
解法：至 C:\xampp\htdocs\opencart\ 手動刪除 install 資料夾。
