新手 vs 老手：六大維度思維蛻變

看清每一次進階在思維、技術與架構上的根本轉變
新手起點 (Novice) 老手巔峰 (Master)
1. 流程事件思維 (Event-driven) 成長 +85%
新手階段： 習慣一行行順序執行，常忘了 Deploy；在 Function 寫了幾十行卻忘記 return msg。
老手境界： 深刻理解「訊息管線」與非同步事件，活用 Change/Switch 節點取代 80% 雜亂代碼。
2. 工業現場感知 (OT & Protocols) 成長 +90%
新手階段： 搞不懂 Modbus Register 偏移與 16 進位 Hex；COM 埠被佔用只會手忙腳亂拔插頭。
老手境界： 善用 Wireshark 抓包剖析 MBAP 標頭與 CRC；融會貫通電磁閥、雙壓閥機電控制邏輯。
3. 戰情視覺美學 (Dashboard & UI) 成長 +80%
新手階段： 隨意拉幾個未對齊的 Text 節點；圖表類型隨便選，連續品質數據畫成圓餅圖。
老手境界： 精通 Dashboard 2.0 Vue 3 架構、直方圖分箱 (Bins) 品質統計、客製 CSS 主題與 ui-template。
4. 雲網串接資安 (Cloud APIs & Security) 成長 +95%
新手階段： 把 API Key 直接明文貼在節點或公開 GitHub；經緯度反填飛機船隻全落到沙漠。
老手境界： 嚴格落實環境變數防禦四大防線；完美串接氣象預報、颱風追蹤與 LINE Bot 自動推播。
5. 邊緣 AI 協同 (Edge AI & Robotics) 成長 +88%
新手階段： 覺得 AI 是深不可測的黑盒子；不知道如何在工廠現場整合視覺辨識與機械手臂。
老手境界： 本地部署 Ollama/AnythingLLM 知識庫；整合 COCO-SSD 與文字語意轉 Epson 手臂實體座標。
6. 系統架構閉環 (MES & Core Internals) 成長 +98%
新手階段： 只能做單機實驗；遇到高頻資料流阻塞 Event Loop 時毫無頭緒，無法串接企業系統。
老手境界： 洞悉 V8 與 libuv 底層機制；以 OpenCart 電商下單驅動 MES 排程、OEE 稼動率與 C# 串接三大方案。

Stage 1：初見流動・破除心魔
基礎語法、核心節點、事件驅動與 msg 物件認知
Level 1：啟蒙幼苗
新手內心 OS (Monologue)
「以前在學校或工廠寫 PLC 階梯圖，或者寫 C 語言都要編譯老半天。Node-RED 只要在網頁上拖拉節點、拉一條線真的就能控制嗎？那個 msg.payload 到底是什麼神秘生物？為什麼我點了 Inject 之後除錯視窗什麼反應都沒有？」
典型心魔與三大踩坑 (Pitfalls)
  • 忘記 Deploy： 改了節點參數卻沒按右上角紅色「Deploy (部署)」，一直在原地苦等結果。
  • Debug 節點瞎子摸象： 只設定印出 msg.payload，看不到整個 msg.topic 或深層屬性，不知道型態是字串還是數字。
  • Function 節點遺漏 return： 寫了 20 行 JavaScript 判斷式，結尾卻忘了寫 return msg;，資料直接被系統丟入黑洞！
破局開悟時刻 (Breakthrough)
「一切皆是 JSON，管線永不停歇！」
當你意識到 Node-RED 根本不是傳統由上而下的循序執行代碼，而是「事件驅動 (Event-driven)」：每一個節點就像工廠輸送帶上的作業員，吃進一箱零件（一個包含 payload 與 topic 的 JSON 物件），動手加工後再沿著輸送帶推進給下一個人。只要這個觀念建立起來，整個宇宙就豁然開朗！
本階段推薦必刷修煉副本： 建議由淺入深依序挑戰
Lab 01: Inject 與 Debug 節點實作 Lab 04~08: Function 節點字串與四則運算 Lab 09: if-else 條件分支判斷 Lab 17~18: Switch 節點條件過濾與分流 Lab 20~23: Change 節點搜尋替代與 JSONata 補充 01: Node.js 與 npm 安裝狀態確認 補充 02: JavaScript 資料型態與節點對應 補充 03: JSON 語法結構與 key-value pairs 補充 11: 變數深度解析 (var vs let vs const) 補充 12: 跳脫字元與本機路徑斜線陷阱

Stage 2：觸碰現場・通訊感知
工業通訊協定、Modbus 暫存器、串列埠與氣壓邏輯實體映射
Level 2：工業行者
新手內心 OS (Monologue)
「單純在電腦上做數值運算很簡單，但一接上現場的溫控器、電表跟 PLC，根本就是外星話！Modbus 的 03 Read Holding Registers 跟 06 Write Single Register 到底是什麼？為什麼手冊上寫 40001，在 Node-RED 填 40001 就讀出亂碼？十六進位 Hex 算到頭昏眼花！」
典型心魔與三大踩坑 (Pitfalls)
  • Modbus 位址偏移 (Offset) 大陷阱： 0-based 與 1-based 混淆，將 40001 直接當成位址填入，結果跟實際暫存器全錯開一位！
  • Serial 串列埠衝突 (Port Busy)： 在打開 Node-RED 讀取 COM3 的同時，背景還開著 PLC 程式或串口助手，導致連線被鎖死丟出 Error。
  • MQTT Topic 訂閱風暴： 隨便在 Topic 填了 # 萬用字元，結果全廠每秒數千筆感測器資料湧進來，整個前端介面卡死。
破局開悟時刻 (Breakthrough)
「用機械氣壓閥懂邏輯，用 Wireshark 抓包看透封包！」
不要把工業通訊當作天書。只要打開 Wireshark 抓包工具，親眼看到 Modbus TCP 封包裡的 7 位元組 MBAP Header 與 Function Code，你會發現它比任何教科書都直觀；再利用「三口二位電磁閥比喻 if-else」、「雙壓閥比喻 AND 邏輯」、「梭動閥比喻 OR 邏輯」，機電硬體與軟體思維在這一刻徹底相融！
本階段推薦必刷修煉副本： 打通硬體與工業協議的神經網絡
Lab 10: 氣壓缸 if-else 邏輯控制 Lab 11: msg.topic 多來源資料分流 Lab 12~14: 檔案讀寫與動態路徑檢驗 專題 03: Serial Port 串列通訊與 PLC 資料擷取 專題 04: MQTT 工業物聯網協議發布與訂閱 專題 09: Modbus TCP/RTU 工業通訊與三菱 FX3U PLC 補充 07: 利用三口二位電磁閥比喻 if-else 補充 08: 利用梭動閥與雙壓閥比喻 OR 與 AND 補充 09: 利用 PLC 階梯圖模擬 if-else 關係 補充 10: 機電丙級第一題動作模擬 and 與 or

Dashboard 2.0 (Vue 3)、直方圖分箱選型、自訂主題與關聯式資料庫
Level 3：數據工匠
新手內心 OS (Monologue)
「只有右邊 Debug 視窗的文字輸出，拿去給老闆或現場廠長看一定會被嫌棄！主管要看全螢幕戰情室、大數字指針錶、即時溫度波動折線圖。而且機台一下班關機，記憶體裡的數據全不見了，歷史趨勢根本留不下來！」

  • 新舊 Dashboard 混部災難： 不知道舊版 Dashboard 1.0 與新版 2.0 (Vue 3) 底層完全不相容，兩種套件混裝導致組件打架、排版崩解。

  • 圖表型態選型錯誤： 把具有連續分佈特性的工件填充重量硬塞成圓餅圖，結果被品保工程師打槍毫無統計意義！

「數據需要有歸宿，戰情需要有靈魂！」
全面擁抱 Dashboard 2.0 (Vue 3 現代化響應式架構)，掌握 Site ➔ Page ➔ Group ➔ Widget 的四層結構；學會品質工程核心的「直方圖分箱 (Bins)」看穿白夜班異常；並結合 XAMPP MariaDB / MySQL 打造標準 CRUD 與歷史時序庫，數據不再隨風而逝，而是轉化為具備商業價值的戰情資產！

Stage 4：跨網互聯・資安覺醒
RESTful API 串接、地理圖資定位、LINE 警報推播與 API Key 資安防洩守則
Level 4：雲端專家
新手內心 OS (Monologue)
「誰說工控系統只能被關在工廠區網裡？我想連上中央氣象署抓颱風警報、串接交通部 TDX 追蹤公車、甚至把異常警報即時發到我跟主管的手機 LINE！等等……怎麼聽說有人把 API Key 寫在流程上傳到 GitHub，結果隔天收到幾十萬的天價帳單？！」
典型心魔與三大踩坑 (Pitfalls)
  • 【世紀大慘劇】API Key 明文外洩： 直接把金鑰 hardcode 在 http request 節點中，一鍵推到公開 GitHub，被爬蟲機器人秒抓盜用。
  • 經緯度填反 (Lat/Lon Inverted)： 地圖節點要求的 lat 與 lon 顛倒，導致台灣海域的船舶航跡全掉在非洲沙漠。
  • HTTP 狀態碼忽視： 忽略 401 Unauthorized、403 Forbidden 或 429 Too Many Requests，流程遇到錯誤卡死無從查起。
破局開悟時刻 (Breakthrough)
「點餐窗口有憑有證，四道防線固若金湯！」
把 API 請求想像成「餐廳點餐窗口」：URL 是櫃檯、Method 是動作、Body 是加點菜單、Headers 就是你的身分憑證。建立「環境變數隔離」、「settings.js 注入」、「IP 白名單綁定」與「費用預警」四大資安防線；掌握 Worldmap 與 LINE Messaging API，正式邁向無疆界的雲地融合專家！

典型架構死穴與排查 (Architecture Pitfalls)
  • Event Loop 阻塞死穴： 在 Function 節點內寫密集迴圈或同步運算，卡死整個 Node.js 單執行緒，導致全廠數百台設備的 WebSocket 同步中斷。
  • IT 與 OT 鴻溝： 商業電商訂單系統（PHP / Web）與工業底層設備（PLC / Modbus）各說各話，缺乏中介層狀態機防呆與重試機制。
  • 微服務雪崩無自癒： 資料庫伺服器偶發斷線時，沒有配置 Polly 斷路器或重試策略，導致連鎖反應癱瘓整條產線。
