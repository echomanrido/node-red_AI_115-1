Framework Architecture

1. 為什麼是 Vue 3？核心架構解析

Vue 3 是 Dashboard 2.0 擁有超高渲染效能、元件靈活度與高擴充性的根本原因。

Proxy 響應式系統

Vue 3 全面採用 ES6 Proxy 替代舊版的 Object.defineProperty。它能攔截任何物件屬性的新增、刪除或陣列變更，當 Node-RED 的 msg.payload 抵達時，畫面立即毫秒級同步！

資料改變 ➔ 畫面自動更新

虛擬 DOM & 靜態提升

工業現場常有一秒數百次感測器數據更新。Vue 3 的虛擬 DOM (Virtual DOM) 與 Patch Flag 技術，只比對真正發生變化的數字或圖表標記，大幅減少真實 DOM 重繪開銷，介面流暢不卡頓。

極低記憶體開銷・極速比對

Composition API

透過 setup()、ref() 與 computed()，工程師能將複雜的數據通訊邏輯、警報判斷拆分成高複用性的組合式函數，大幅優化自訂元件維護效率。

邏輯解耦・模組化複用

Vuetify 3 視覺元件庫

Dashboard 2.0 內建 Vuetify 3，所有開關、按鈕、滑桿皆符合 Material Design 規範。只要理解其 Class 名稱（如 .v-btn、.v-card），就能運用 CSS 全局換膚！

開箱即用的現代化工業元件

2. 網頁三劍客：HTML、CSS、JS 分別的作用

在 Node-RED 的 ui-template 節點中，這三者協同合作，構建出兼具結構、美感與互動能力的儀表板。

骨架與結構 (Structure)

HTML

「建築的地基與鋼筋骨架」

HyperText Markup Language 定義了網頁內容的語意與層次。它負責告訴瀏覽器哪裡是標題、哪裡是按鈕、哪裡是儀表指針或表格容器。

<!-- 建立儀表按鈕骨架 -->
<button class="v-btn">
啟動主發電機
</button>
在 Dashboard 2.0 中：
提供卡片、標籤、容器與 Vue 範本語法（如 v-if, v-for）。
外觀與皮膚 (Presentation)

CSS

「室內裝潢、皮膚與衣著美感」

Cascading Style Sheets 掌控所有視覺呈現。負責顏色、漸層（linear-gradient）、圓角（border-radius）、排版間距、陰影與毛玻璃質感。

/* 給按鈕加上圓角與高光 */
.v-btn {
border-radius: 10px !important;
background: #245aa5;
}
在 Dashboard 2.0 中：
這正是你截圖中編寫的區塊！用 <style> 注入全局漸層與元件圓角。
大腦與靈魂 (Behavior)

JavaScript

「肌肉反應、神經系統與大腦」

JavaScript (JS) 掌控邏輯與即時互動。負責發送/接收 WebSocket 封包、監聽點擊事件、計算感測器平均值、觸發警報音效與畫面重算。

// 監聽點擊並發送 payload
function onClick() {
this.send({ payload: 'START' });
}
在 Dashboard 2.0 中：
搭配 Vue 3 Composition API，在前後端之間建立起活生生的資料雙向流動。
一句話總結： HTML 畫出按鈕（骨架），CSS 讓按鈕擁有 10px 圓角與炫麗漸層（皮膚），JS 讓按鈕點擊後能啟動馬達（靈魂）。

3. 圖解核心教學：解析你截圖中的範例代碼

深入探討如何透過 ui-template 節點注入 CSS，置換全螢幕背景漸層與按鈕圓角。

重點 1：全域背景與漸層穿透 #app, .v-application

在 Vue 3 / Vuetify 中，整個畫面的最外層根節點為 #app，而主題視窗通常為 .v-application。

/* Main background 全域背景 */
#app, .v-application {
background: linear-gradient(135deg,
#0f172a 0%,
#245aa5 50%,
#b800e9 100%
) !important;
background-attachment: fixed !important;
}
  • linear-gradient: 透過多色標（例如 #245aa5 在 50%、#b800e9 在 100%）營造精緻的光影流動感。
  • !important: Vuetify 3 內部有預設的深色/淺色主題背景顏色，必須使用 !important 強制權重覆寫。
  • background-attachment: fixed: 當儀表板頁面滾動時，背景固定不移動，維持高品質視覺沉浸感。
重點 2：元件圓角風格美化 .v-btn, .v-list-item

Vuetify 3 的按鈕預設為微圓角 (4px)。若要打造現代感的流線、軟性或膠囊風格介面，可覆寫其圓角半徑。

/* Hover selection - 按鈕與連結圓角 */
.v-list-item, .v-btn {
border-radius: 10px !important;
}
  • .v-btn: 涵蓋儀表板中所有普通按鈕（如觸發 inject、切換開關、送出表單按鈕）。
  • .v-list-item: 涵蓋側邊導覽抽屜（Navigation Drawer）、下拉選單（Dropdown / Select）選取的選項。
  • 視覺一致性: 統一按鈕與導覽列選取項的圓角尺寸，能大幅消除雜亂感，呈現一體成型的 UI。
