var・let・const 差異與底層原理實戰

三大宣告關鍵字 核心差異矩陣

一眼搞懂底層作用域（Scope）、提升（Hoisting）與不可變性（Immutability）的規則。

比對維度 var (舊時代 ES5) let (現代 ES6) const (現代 ES6)
有效作用域 (Scope) 函式作用域 (Function Scope) 區塊作用域 (Block Scope `{}`) 區塊作用域 (Block Scope `{}`)
重複宣告 (Re-declaration) 允許（容易引發意外覆蓋） ❌ 禁止（SyntaxError） ❌ 禁止（SyntaxError）
重新賦值 (Re-assignment) 允許 (`x = 20`) 允許 (`x = 20`) ❌ 禁止（TypeError）
變數提升 (Hoisting) 提升並初始化為 undefined 提升但進入 暫時性死區 (TDZ) 提升但進入 暫時性死區 (TDZ)
全域物件綁定 (window) 會成為 window.varName 不會污染 window 不會污染 window
現代開發建議 徹底捨棄不使用 僅在數值確定會改變時使用 首選與預設使用

const 房子門牌與內部家具
