工業機器手臂與程式開發教學

基於 EPSON RC+ 7.0 及 SPEL+ 核心技術指南

⚙️ 工業機器手臂五大結構與全球四大廠商

根據投影片架構，工業機器人依機構分為單軸、直角坐標、SCARA（水平多關節）、並聯式（DELTA）及垂直多關節機器人。

1. 單軸機器人

多應用於單軸移載、精密滑台，內部含有螺桿、滑塊與馬達座。

2. 直角坐標機器人 (Cartesian)

沿 X、Y、Z 直角軸向運動，結構簡單、精度高，常用於CNC上下料與點膠。

3. 水平多關節 (SCARA)

EPSON 招牌主力，具備高剛性水平運動與快速上下（Z軸）能力，廣泛用於電子組裝。

4. 並聯式機器人 (DELTA)

頂部固定，透過多支主動臂與從動臂高速分揀，常見於食品包裝與高速生產線。

5. 垂直多關節 / 6軸機器人

模仿人手臂結構（前三軸決定位置，後三軸決定姿態），空間靈活性極高。

🌍 全球四大機器人大廠

瑞士 ABB、日本 FANUC (發那科)、德國 KUKA (庫卡)、日本 YASKAWA (安川電機)。

📐 座標系統與 ECP (外部控制點)

常見座標系介紹

  • 世界座標 (World)： 機器人的原生預設基本座標系統。
  • 本地座標 (Local)： 位於工作空間某處的使用者自定義座標。
  • 工具座標 (Tool / TCP)： 位於機械手臂夾具末端工具的中心點。
  • 關節座標 (Joint)： 直接控制各軸馬達轉動角度。

ECP (External Control Point)

外部控制點是指原點位於外側固定工具尖端（如固定注射針頭）的座標系統。

當使用 Move P2 ECP 時，夾持工件的手臂會沿著外部工具尖端邊緣進行精準軌跡與姿態移動，非常適合點膠或塗膠應用。

🦾 機械手臂方向 (Arm Orientation)

開發系統時必須指定針對特定手臂方向所示教的點資料，若未正確指定可能導致軌跡偏移或干涉周邊設備。

SCARA 手臂方向

分為 Righty (右手方向) 與 Lefty (左手方向)，決定第一與第二關節的彎曲相對位置。

6軸手臂方向組合

包含：
• Hand (Righty / Lefty)
• Elbow (Above / Below)
• Wrist (NoFlip / Flip)

旗標值 (Flags)

利用 J1Flag、J4Flag、J6Flag 來精準記錄多回轉軸的群組與姿態狀態。

⚠️ 奇異點 (Singularity) 原理與迴避

當機器手臂處於特定姿態時，其數學模型中的雅可比矩陣 (Jacobian Matrix) 行列式值為零，導致逆矩陣不存在。此時若發出微小的末端移動指令，會造成某些關節速度趨近於無限大，導致機械卡住、報錯或劇烈震動。

腕關節奇異點 (Wrist Singularity)

第 4 軸與第 6 軸共線時發生，會嘗試瞬間轉動 180 度。

肩關節奇異點 (Shoulder Singularity)

第 1 軸與腕關節中心 C 點共線時發生。

肘關節奇異點 (Elbow Singularity)

腕關節中心與第 2、3 軸共平面，肘部被鎖住無法移動。

💡 如何避免奇異點？

  • 使用 7 軸冗餘機械手 (Redundant Robot) 增加自由度。
  • 調整工具法蘭面角度 (5° ~ 15°)。
  • 在非必要直線運動時，將 Move（線性運動）改為 Go（PTP關節運動）。

💻 運動命令與 SPEL+ 程式語言

常用運動指令對照

  • Go P1： PTP 點到點運動，路徑不一定是直線。
  • Move P2： 線性運動 (CP動作)，沿直線移至指定點。
  • Jump P3： 門形動作（先往上抬至 LimitZ，再平移，最後下降）。
  • Arc / Arc3： 圓形插補與 3D 圓弧移動。
SPEL+ 程式碼範例 (Main.prg)
Function main
    Call init
    Do
        Go P1
        Move P2
        Move P3
        Go P1 +Z(200)
    Loop
Fend

Function init
    If Motor = Off Then
        Motor On
    EndIf
    Power Low        ' 設定運行功率
    Speed 10         ' PTP 運動速度 (%)
    SpeedS 500       ' CP 直線運動速度 (mm/s)
Fend
