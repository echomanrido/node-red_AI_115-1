即時追蹤之 IF-ELSE 程式碼（隨運行亮起）:
// 步進狀態 S20: 進料與判別循環
IF Step = S20 THEN
Y002 := TRUE; // [SET Y002] 輸送帶運轉
Y015 := TRUE; // [SET Y015] RL 運轉紅燈亮
// 10秒逾時計時器 (無料時累加)
IF NOT X002 THEN T0 := T0 + ScanTime; ELSE T0 := 0; END_IF;
// (A) 逾時 10 秒條件分支: 終止循環回待機
IF T0 >= 10.0 THEN
Step := S1; // [SET S1] 回到待機狀態，RL滅，GL亮
// (B) AND 串聯條件: NOT T0 AND X002 (未逾時 且 s0進料感測)
ELSIF (NOT T0_Done) AND X002 THEN
T1 := T1 + ScanTime; // 啟動 (T1 K10) 1秒計時器
IF T1 >= 1.0 THEN // 1秒到位，觸發 T1 常開接點
Y002 := FALSE; // [RST Y002] 輸送帶停止
// 形狀判別 IF-ELSE: 圓形(X003=1) vs 方形(X003=0)
IF X003 THEN
M1 := TRUE; // [SET M1] 標記為圓形料件 (送往上方)
ELSE
M1 := FALSE; // [RST M1] 標記為方形料件 (送往下方)
END_IF;
Step := S30; // [SET S30] 移交至龍門手臂夾取
END_IF;
END_IF;
END_IF;
// 機丙第一站主狀態機 - S20 進料與判別循環
if (step === 'S20') {
Y002 = true; // 啟動輸送帶馬達
Y015 = true; // RL 運轉紅燈亮
// 1. 逾時判定分支 (OR 條件 1)
if (T0 >= 10000) {
step = 'S1'; // 逾時無待料，終止循環回待機
// 2. AND 串聯邏輯: (!T0_timeout && s0_sensor)
} else if (!T0_done && X002_s0) {
T1 += deltaTime; // s0 感測到料件後開始計時 1 秒
if (T1 >= 1000) { // 定位完成 (T1 K10)
Y002 = false; // 輸送帶停止
// 3. 形狀判別 IF-ELSE 結構
if (X003_s1) {
M1 = true; // 圓形料件 (s1 檢出 ON)
} else {
M1 = false; // 方形料件 (s1 檢出 OFF)
}
step = 'S30'; // 轉移至機械手臂取料排料
}
}
}

AND（及）邏輯：串聯接點

在梯形圖第 5 列中，計時器 T1 的驅動條件為： /T0 (未逾時) AND X002 (s0進料感測)。

NC 接點 /T0 1 (導通)
AND
NO 接點 X002 0 (未導通)
=
T1 啟動條件 0 (停止)

★ 意義：只有在「尚未超過 10 秒等待逾時」且「料件確實到達 s0 感測位置」時，才允許啟動 1 秒定位停止計時器。

OR（或）邏輯 / 分支判別架構

本梯形圖中包含兩種重要的並聯結構：

  1. STL 母線並聯驅動 (並聯執行)：進入 S20 後，母線同時對 SET Y002、SET Y015 與 T0 得電，三者同步執行。
  2. 形狀互斥分支判別 (條件分流)： 當 T1 計時 1 秒到達後：
    • 若 X003 = 1 (形狀辨別感測到圓形) $\rightarrow$ [SET M1] 標記為圓料。
    • 若 X003 = 0 (形狀辨別常閉接點導通，為方形) $\rightarrow$ [RST M1] 標記為方料。
