Epson 機器手臂 C# 開發教學

基於 RCAPINet.dll 與 EPSON RC+ 7.0 整合指南

1. C# 專案建立步驟

首先在 Visual Studio 中建立專案：

  • 選擇專案範本：Windows Forms App (.NET Framework)。
  • 支援語言：C#。適用於建立具有 Windows Forms (WinForms) 使用者介面之應用程式專案。
Windows Forms App (.NET Framework)

目標框架通常為 .NET Framework 4.x

2. 加入 RCAPINet.dll 參考

若要透過 C# 控制 Epson 手臂，必須在專案的「參考」中加入對應的元件庫路徑：

C:\Windows\Microsoft.Net\assembly\GAC_MSIL\RCAPINet\v4.0_1.0.0.0__0487594b04a8fcc0\RCAPINet.dll
程式碼開頭需引入命名空間：using RCAPINet;

Spel 類別核心方法與範例

PTP 移動

Go 方法

以 PTP (Point-to-Point) 形式將手臂從目前位置移至指定點或 XY 位置。

m_spel.Go(100);
m_spel.Go("P0 /L /2 ROT");
線性移動 (CP)

Move 方法

使用 CP 動作(直線移動)，將手臂從目前位置移至指定點。

m_spel.Tool(1);
m_spel.Move(100);
SpelPoint pt = m_spel.GetPoint("P0");
pt.X = 125.5; m_spel.Move(pt);
相對運動

JTran / PTran

JTran：相對關節移動(度/公釐)。
PTran：以脈衝為單位的相對移動。

// 以正方向將關節 1 移動 45 度
m_spel.JTran(1, 45.0);

GetRobotInfo 與屬性

取得手臂型號與狀態：

SpelRobotInfo info;
info = m_spel.GetRobotInfo();
label1.Text = info.RobotNumber + " " + info.RobotModel;

// 馬達與功率狀態
m_spel.MotorsOn = true;
m_spel.PowerHigh = true;

執行方法 (同步與非同步)

  • 立即方法：I/O 等指令會立即傳回回覆。
  • 非同步方法：如機器人動作命令，Spel 執行個體會等待來自 EPSON RC+ 伺服器的完成事件。
  • 可設定 AsyncMode = false 或執行 WaitCommandComplete() 等待完成。

常見例外狀況與排除 (Troubleshooting)

錯誤 1808

RCAPINet.SpelException: '!!錯誤: 1808, 未安裝USB驅動器。'

通常發生於實體連接埠或模擬器未正常辨識時。請參照相關技術文件或檢查 Epson RC+ 控制器連線設定。

錯誤 10007

RCAPINet.SpelException: '!!錯誤: 10007, 專案不存在。'

原因：EPSON RC+ 找不到指定的專案路徑（例如原先指到自訂專案 c:\EpsonRC70\Projects\Rido\MoveGo\MoveGo.sprj 但檔案遺失）。
解決方法：

  1. 開啟 EPSON RC+ 7.0 軟體。
  2. 點選功能表 設置(U) -> 電腦與控制器通信(C)，確認虛擬控制器狀態。
  3. 若專案遺失，改為指向內建的範例專案，例如：
    c:\EpsonRC70\Projects\SimulatorDemos\C4_sample\C4_sample.sprj
  4. 透過 專案(P) -> 打開(O)... 重新載入對應的模擬器範例。
