01

建立 Google Firebase 專案

前往 Firebase 控制台建立並設定新專案環境

操作步驟

  • 前往 Firebase 官網 並點擊「Go to console」。
  • 點擊「建立新的 Firebase 專案」，輸入專案名稱（如 calendar）。
  • 啟用建議的 **Gemini in Firebase** AI 輔助功能。
  • 啟用 **Google Analytics** 數據分析功能，位置選擇「台灣」，勾選條款並建立專案。

提示

建立完成後，系統會自動分配專案 ID（例如 calendar-1a655）。數據分析功能將提供免費報表與 A/B 測試支援。

02

連結網頁應用程式 (Web App)

將專案與您的前端網頁進行串接與初始化

1. 註冊應用程式

於專案設定中的一般設定頁面，點擊網頁圖示 </>，輸入應用程式暱稱（如「行事曆」）並註冊。

2. 安裝與初始化 SDK

使用 npm 安裝：npm install firebase，並複製初始化設定物件。

03

建立 Cloud Firestore 資料庫

設定 NoSQL 雲端資料庫版本與儲存位置

1. 選取版本

選擇 **Standard 版**（簡易查詢引擎，支援自動建立索引與核心作業）。

2. 選擇位置

資料庫 ID 保持預設 (default)，位置選擇 nam5。注意：位置一經設定無法變更！

3. 安全性模式

可先選擇**正式版模式**（預設拒絕所有未授權讀寫），後續再調整規則。

04

安全規則設定與資料結構

發布規則並理解 Collection 與 Document 階層

安全性規則調整 (Rules)

在開發階段若需要完全開放讀寫，可將規則修改為：

rules_version = '2';

service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
