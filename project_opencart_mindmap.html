1. OpenCart 前台工件選購商城

Storefront
http://localhost/opencart/index.php?route=product/category
勞動部產品專區 (Ministry of Labor)
塑膠工件 ($89) / 金屬工件 ($49)
  • 專屬分類：前台僅保留「勞動部產品」分類，其餘樣品一律批次停用。
  • 客製化加工規格：下拉選單提供 Process (需切削) 與 No Process (免切削)。
  • 購物車與結帳：加入購物車後模擬結帳，資料寫入 oc_order 與 oc_order_product。
進入主題二：前台下單模擬器

2. OpenCart 後台管理與狀態配置

Admin Dashboard
http://localhost/opencart/admin/ (Orders & Localisation)
Order Statuses 狀態碼維護
代碼 99 (加急) / 代碼 5 (Complete 已完工)
  • 自訂加急狀態：於 System > Localisation > Order Statuses 建立「加急處理」。
  • 即時雙向連動：現場 MES 加急或完工時，後台訂單清單狀態即時刷新變更。
  • 完整生產履歷：oc_order_history 忠實保存作業員加急與完工之時間戳記。
查閱後台設定教學章節

3. MariaDB / phpMyAdmin 資料庫終端

Port 3306
http://localhost/phpmyadmin/ (db_opencart)
SQL 原生查詢與兩階段巢狀子查詢
SUM(total_quantity) FROM (SELECT ... GROUP BY)
  • 未完工單精準篩選：WHERE order_status_id != '5' AND != '7'。
  • 多表關聯查詢：LEFT JOIN oc_order_option 提取客製化切削選項。
  • 兩階段巢狀統計：外層 SUM 加總內層按訂單分組件數，防範重複多計。
進入主題三：SQL 互動沙盒

4. Node-RED 工業 MES 戰情室 Dashboard

Port 1880/ui
http://localhost:1880/ui/ (MES Control Panel)
動態 LED 圓形指示燈 + Gauge 儀表
msg.options 驅動下拉選單・4秒切削模擬
  • 動態工單下拉：Function 節點組裝 msg.options 驅動 Dropdown 選單。
  • 動態圓形 LED 燈：HTML/CSS 模板呈現綠燈待機、黃燈切削與藍燈完工。
  • SCADA 圓形 Gauge：實時計算全廠良率，指針動態旋轉切換綠/黃/紅。

5. C# .NET 8 / WPF 智慧機電上位機戰情室

Vibe Coding Architecture
SmartFactory.MES.Client.exe (WPF .NET 8.0-windows)
強型別・高併發・Dapper 事務安全・多執行緒切削狀態機
適用於精密製造現場與全國競賽 PC-Based 上位機實戰
  • Dapper ORM：參數化查詢徹底杜絕 SQL Injection，提升吞吐量。
