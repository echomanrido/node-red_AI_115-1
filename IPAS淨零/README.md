# IPAS 淨零碳盤查課程與教材專區

本專區彙整經濟部產業發展署「淨零碳盤查」與「低碳人培」之官方教材、培訓講義及活動影音資源，供機電 AI 班學員進行 ESG 與綠色智慧製造之延伸研習。

- **簡介**：涵蓋最新組織溫室氣體盤查規範（ISO 14064-1）、產品碳足跡（ISO 14067）、排放係數計算及盤查報告書編製實務。

- **連結**：[點此前往活動影片/教材專區](https://sdd.nat.gov.tw/ghg/CVData/index)

## 智慧機電整合應用連結

在機電整合與 SCADA 監控系統中，碳盤查與智慧量測之實務結合點：
1. **電力監控與能源碳排（範疇二）**：透過 Modbus RTU/TCP 讀取電錶（如 kWh、kW、PF），於 Node-RED 或 C# 即時換算台電電力排放係數（$\text{kg CO}_2\text{e}/\text{kWh}$）。
2. **產線即時單件碳足跡（ISO 14067）**：結合實務專題之機電整合丙級第二題機台，將加工氣壓功耗、電能與物料耗損轉換為單件工件的動態碳足跡指標。
3. **雲端碳履歷上傳**：透過 MQTT 或 RESTful API 即時將廠端能源消耗數據同步至雲端 ESG 數據中台。
